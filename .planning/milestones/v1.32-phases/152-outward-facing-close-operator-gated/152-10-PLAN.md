<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| devcontainer layout → CI layout | The devcontainer has a sibling firmware checkout CI does not; a test that reads across repos passes locally and fails in CI. |
| devcontainer interpreter → CI interpreter | The local interpreter is a minor version ahead of the one CI uses, so a local green can be fail-open. |
| local branch → `origin/beta` | Every push to `beta` cuts a pre-release. Anything dirty or broken at this point becomes a published artifact. |
