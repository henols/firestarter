<objective>
Establish the two things every later firmware plan depends on and neither can create retroactively:
a v1.32 firmware branch forked off `origin/beta`, and a **cold** flash/RAM measurement taken at that
fork point **before the first firmware edit**. Then create `149-PAGE-SIZE.md`, the phase's single
review artifact, pre-loaded with the measurement and the D-01 provenance evidence.

This plan is first by hard ordering constraint (`149-RESEARCH.md` §Preconditions P-1/P-2, §Pitfall 5).
ROADMAP criterion 4 requires deltas "recorded against a baseline captured before the first firmware
edit". A capture taken after any edit cannot satisfy it, and no later plan can repair that.

`firestarter/` is currently on `gsd/v1.31-27c-programming-algorithm-fidelity` @ `6992271`. This is the
plan that fixes that, and it verifies the fork **by content** because the v1.31 PRs were squashed and
`git merge-base --is-ancestor` returns false negatives.

Purpose: make PGSZ-04's flash and RAM deltas attributable to this phase rather than inherited,
in either direction (D-13).
Output: a forked firmware branch, three committed cold `pio run` transcripts, and the
`149-PAGE-SIZE.md` skeleton. Everything this phase records about the page-size change is
**software-proven and unvalidated on silicon**.
</objective>
