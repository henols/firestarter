<objective>
Correct the one user-visible string that becomes false, and record the new flag semantics in the two
command docstrings — without adding the second warning the symmetry invites.

outward-claim gate exists to catch — cheaper to fix here than to have that gate catch our own text.

verified-green pinning suite.

**Requirement flips owned by this plan: none.** It advances ERASE-03.

vacuous on the write path because no erase-on-write block was added).
