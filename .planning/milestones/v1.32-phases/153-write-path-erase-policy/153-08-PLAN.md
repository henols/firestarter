<objective>
Record the 84-record wire-value change ERASE-03 produces as a committed, reviewable delta list, and
extend the equivalence gate to compose two delta layers over an untouched golden.

Purpose: restoring `FLAG_CAN_ERASE` moves `flags` from the old value to the new one on exactly 84 of
the 746 wire dicts. The 746-chip equivalence gate is the only place in either repository where wire
*values* are compared, and it is deliberately built so that a legitimate change must be enumerated
by name rather than absorbed by a re-capture.

Output: one new delta file with 84 entries and a `meta` block, and an extended test module whose new
assertions are each non-vacuous by construction.

**Requirement flips owned by this plan: none.** It advances ERASE-03.
</objective>
