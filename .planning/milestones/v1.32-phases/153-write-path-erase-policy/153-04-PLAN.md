<objective>
Invert the two firmware assertions that say `CMD_ERASE` cannot exist on `0x0D`, and add the cases
that prove the new operation really emits the sequence rather than merely dispatching.

Purpose: ERASE-03's firmware proof and ERASE-04's stream proof. Adding the switch arm removed this
`(cmd, protocol)` cell from Phase 119 D-06's op-layer NULL-main guard — the guard that existed
precisely to stop a destructive command reporting OK having done nothing. So the replacement proof
must be about the *emitted stream*, not about dispatch resolution.

Output: one split function, one inverted end-to-end case, three new stream cases, one new no-VPP
configure case, and a fully green native suite in both environments.

**Requirement flips owned by this plan: ERASE-03 (firmware half).** ERASE-04 flips once plan 05's
negative source scan lands.

Cites `D-153-02` (the prefix, whose presence Case 31 and Case 33 pin) and `D-153-03` (this plan
covers the *configure* phase and the *stream*; the erase **body** scan is plan 05).
</objective>
