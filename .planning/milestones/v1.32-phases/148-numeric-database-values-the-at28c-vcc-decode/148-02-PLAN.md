<objective>
Make `diff_db.py` (GATE-02) schema-agnostic **before** the schema moves, so the gate never goes RED
for a representation reason and the blast-radius proof stays trustworthy end to end.

`tools/baseline/chip_database.baseline.json` is **NOT re-pinned** (**D-11**) — the comparison stays
live against a baseline that predates Phase 136.1. Landing this plan first is what makes that
possible: a canonicalizer normalizes *both* sides to millivolts and microseconds before comparison,
so it is correct against an old-schema current database (today) **and** against a new-schema one
(after Plan 03). That property is the plan's own proof.

**D-11's stated mechanic is incomplete and RESEARCH.md measured why.** Four coordinated edits are
required, not one. This plan lands three of them; the fourth — the `RULE_VCC_MARGIN_RAIL` rule
itself — belongs to Plan 06, because the 56 movers do not exist until the D-03 rule runs.

Purpose: keep the review artifact honest through a schema change.
Output: a comparator that yields byte-identical bucket counts on both schemas.
</objective>
