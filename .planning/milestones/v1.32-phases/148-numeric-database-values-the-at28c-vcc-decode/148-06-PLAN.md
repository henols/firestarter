<objective>
Correct the AT28C family's VCC — and every other part whose decoded VCC is the TL866's 4 V
verify-margin rail — to the 5 V supply the parts actually run at, in `build_db.py`'s decode
function, with `chip_database.json` regenerated from it.

**The premise DATA-01 originally carried is false and was hand-corrected before planning (D-04).**
`vcc: "4V"` is a **faithful** decode: `VCC_VOLTAGES` (`build_db.py:193`) maps `infoic.xml`'s VCC
nibble `2` to 4 V and is `[VERIFIED: minipro database.c#L130-L135 @ a8efaedc —
tl866ii_vcc_voltages[]]`; index `0x02` was added deliberately by the BUG-1 fix (**D-01**). There is
no arithmetic defect to repair. The defect is **semantic**: minipro's `vcc` is the TL866's
low-margin verify rail, and firestarter surfaces it as the chip's operating supply — the same
category error the shipped SRAM normalization (`build_db.py:807-821`) already corrects for
static-memory parts.

The target is **5000 mV — the already-decoded `vdd`, not 4500 mV** (**D-02**). 4500 mV is a value
`infoic.xml` does not carry for these parts (their nibble is `2`, not `3`), it is a datasheet
*minimum* where every other VCC row reports the *applied* supply, and inventing it would violate
DATA-04's proof rule. `vdd` is itself an `infoic.xml`-decoded value, so substituting it invents
nothing.

The condition is keyed on the **decoded value alone** — `vcc_mv == 4000` -> `vdd_mv` (**D-03**). No
part number, no type, no algorithm, so it cannot become a `_PAGE_SIZE_BY_PART` sibling (DATA-04).

**Evidence Ceiling (binding).** No AT28C part exists in operator inventory. This plan corrects
**data the generator emits** and makes **no claim** about AT28C silicon behaviour: `0x0D` stays
`UNVERIFIED`, no `support_status` changes, and gh#21 / #32 / #11 / #12 stay OPEN. Per **D-06**
`vcc` is inert on the wire, so nothing here can explain or fix `write BAD`.

Purpose: close DATA-01 and prove DATA-05's blast radius.
Output: 56 chips moved `4000 -> 5000`, in their own labelled `diff_db` bucket, with a captured
RED->GREEN transcript proving the new rule is load-bearing rather than decorative.
</objective>
