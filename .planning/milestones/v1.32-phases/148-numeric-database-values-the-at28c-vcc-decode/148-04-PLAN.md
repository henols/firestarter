<objective>
Delete `database.py`'s string-coercion layer — **gone, not bypassed** — and replace it with one
shared millivolt-to-string render helper, so `database.py` goes from "parses strings into numbers"
to "owns the numeric convention and renders it". One clean reversal, in one file (**D-16**).

This plan is where the phase's central safety claim is proven. **D-14**: the 746-chip wire-dict
captured in Plan 01 must come back **byte-identical**. **D-06**: `vcc` and `vpp_volts` never leave
the host, so nothing here can change `write` behaviour. **D-15**: the render contract is
byte-exact, so `tests/__snapshots__/test_characterization.ambr` must be **byte-unchanged**.

RESEARCH.md F-3 corrected D-15's stated proof: **no AT28C VCC line exists in any snapshot** — the
only info-view snapshot runs `firestarter info W27C512`, which is not a mover. The correct and
stronger criterion is that the `.ambr` does not move at all. Do not plan a re-baseline.

Purpose: close DATA-03 and the display half of DATA-02 without moving a single rendered byte.
Output: a coercion-free `database.py`, three call sites on one helper, and a green wire-dict
equivalence test.
</objective>

<planner_decisions>
- **P-02 (D-16 helper name and location).** `format_mv(mv: int) -> str` in
  `firestarter/database.py`, module level, in the band vacated by `_parse_pulse_duration`
  (`:128-143`) — after `logger = logging.getLogger("Database")` (`:126`), before
  `_read_config_file` (`:146`). **Public** (no leading underscore) because two other modules import
  it. Returns `f"{mv / 1000:.1f}v"`.
- **P-03 (RESEARCH Open Question 1 — settled here).** `format_mv` is **strict**: no `'N/A'`
  fallback inside the helper. D-10 puts the strictness in `_map_data` (direct indexing; an absent
  key raises rather than resolving to a valid-looking `0`), so by the time a render site runs the
  value is guaranteed to be an int. A tolerant fallback inside the helper would recreate in the
  display layer exactly the tolerant-reader shape D-07 forbids. The **existing** `try/except`
  int-coercion at `ic_layout.py:589-592` and `eprom_info.py:391-394` **stays** — it guards the
  `vpp_mv > 0` *gate*, which is a separate concern — and its already-coerced `_vpp_mv` local is
  what is passed to `format_mv`.
- **P-07.** The dead `vpp_volts` fallback in `convert_to_programmer` (`:544-547`) and the
  `"vpp_volts"` mapped-dict key (`:414`) are both **deleted**. This is what forces the two
  `vpp_str` sites onto `vpp_mv` + `format_mv`; CONTEXT.md names the sites but not this coupling.
- **Render contract is locked (D-15).** `f"{mv / 1000:.1f}v"` reproduces all 13 distinct database
  values byte-exactly (`3.3v`, `4.0v`, `5.0v`, `5.5v`, `6.5v`, `9.0v`, `12.0v`, `12.5v`, `13.0v`,
  `13.5v`, `18.0v`, `21.0v`, `25.0v` — RESEARCH §"Render Contract"). Do not change the format.
  Datasheet-style rendering (`"5V"`) was **considered and declined**, not deferred.
</planner_decisions>
