<objective>
Give the app's `[dev test]` triage render a labelled firmware-identity line, an explicit
not-attributable clause when that identity is absent, and — for the first time in this repo — tests.

Purpose: PROV-06 exists so a maintainer can attribute a community report to a firmware version
*without asking the reporter*. CONTEXT.md described this surface as having "committed CI-run tests";
RESEARCH measured that a repo-wide grep for `render_diff` returns **only its definition and its single
call site**. So PROV-06's automated oracle has to be created, or the requirement ships on an
unexercised code path — the volume-without-reachability shape this project has been bitten by before.

Output: two new labelled rows in `render_diff`, the parser's own copy of the marker literal, a
value-parity assert standing in for the import architecture forbids, and a null-identity frozen fixture
proving PROV-04's real-world case.

**Evidence Ceiling (binding, PROJECT.md §Current Milestone: v1.32).** The not-attributable clause says
a report cannot be tied to a firmware version and asks for a fresh run. It may not say or imply the
`0x0D` write path is proven, that a support status changes, or that gh#21/#32/#11/#12 are closed.

**No firmware change.** `firestarter/` is read-only reference; Phase 149 owns the only
firmware-touching workstream.
</objective>
