`check_sdp_capability_invariants.py`'s exact shape, extended by the one rule that has no
analog in the tree: a three-axis literal table with two gated symbols instead of one, and a
Class 1(a) whose forbidden return value is a class-token string rather than `True`.

Purpose: LOCK-01. Nothing structurally prevents a future edit from widening the readable
token set back into inference, or from adding a permit path not dominated by a membership
test. The analog denies exactly that for one boolean symbol; `PATTERNS.md` records the
three-axis case as **no analog found**, extensible per its Option A by parameterising the
gate's single `_TOKEN_SET_NAME` string into a tuple of names.

Option A is taken deliberately, and the reason is recorded here: it preserves the gate's
strongest existing property — literal-`frozenset`-only — for free on the one axis that gates
behaviour, and confines invention to a reporting mapping documented as weaker. Option B (one
literal dict of three-tuples) would additionally break Class 1(a) dominance detection, because
`TABLE[token][1]` is an `ast.Subscript` rather than an `ast.Compare`, so
`_is_membership_test_against_token_set` would no longer fire and the permit path would look
undominated.

Output: the gate, its paired subprocess-driven test with nine mirrored legs, and two committed
planted fixtures.
