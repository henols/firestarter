<objective>
Make the three write-path diagnostics that 203-REVIEW flagged tell the truth, without changing any
safety decision or exit code: D-08 (a negative start address gets the negative-address message even
when it is also misaligned), D-07 (an incomplete guard read names no fabricated byte) and D-06 (a
landed write whose `--skip-sdp-unlock` ack is missing gets its own line).

Purpose: each of these is a message an operator reads when something went wrong. Today two of them
state something false (a byte that was never read; a write that "did not complete" when it landed)
and one hides the clearer of two true refusals. The refusals stay fail-closed; only the words change.

Output: two new message constants plus one helper, one gate swap at two call sites, one new CLI arm,
five new tests, one rewritten pin. Covers audit items 203 WR-01, 203 WR-02 and 203 IN-01.
</objective>
