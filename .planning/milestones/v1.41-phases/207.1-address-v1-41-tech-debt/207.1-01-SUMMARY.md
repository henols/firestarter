## Decisions Made

- **D-08 test data inverted from the CONTEXT premise:** used a *misaligned* negative address (W29C020 at `-1`, page size 128) rather than merely negative, because 207.1-RESEARCH.md's own investigation found a negative, page-*aligned* address already got the clearer message today — only the misaligned case was losing it to the page-alignment gate. Both new tests and both source comments reflect this corrected premise.
- **D-07's exact sentence was authored to satisfy two structural constraints simultaneously:** it must keep D-10's no-remedy property (no `-b`/`--no-blank-check`/`bypass`/`skip` substring) while never containing the word "non-blank" (whose embedded hyphen-b would itself trip the `-b` forbidden-substring check). The chosen sentence — "the blank check read only {compared} of {total} bytes; every byte it read was blank, but the region is not proven blank." — satisfies both.
- **D-06's new arm placement:** inserted after the `attempt_verdict == 2` arm and before the arm-4 default, keyed on `attempt_verdict == 0` — the value `write_eprom` records before the `--skip-sdp-unlock` ack block can flip `is_ok`, so this arm is reachable only through that one ack-failure path.
