## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| operator input → host pre-connect gates | The `-a` start address and the input-file length reach `require_page_size`, `require_non_negative_address` and `require_page_alignment` before any connect. | CLI arguments, file length |
| host guard verdict → hardware write | The blank-guard verdict decides whether `COMMAND_WRITE` is ever sent to a UV or EEPROM part. | guard verdict, compare coverage |
| host output → operator decision | Verdict and refusal lines steer what the operator does next: retry, erase, or investigate firmware. | log lines, exit codes |
| host transport → firmware | `setup_command` sends the command frame. A send on a dead link is the precondition D-11 asserts. | command frames |
| firmware timing → host verdict | The arrival time of `MSG_ERR_TIMEOUT` relative to the host's stop decides verdict 1 or 2. | timing |
| repository → release pipeline | `beta-release.yml` and `release.yml` run `.github/scripts/update_version.py` on push. | version string |
| host fingerprint → public issue tracker | `dedup_fingerprint` groups filed `dev test` reports. Its pre-image is external state. | fingerprint pre-image |
| app working tree → meta repository | A bench log moves from an untracked file into a tracked record that can become public. | port name, controller identity, timings |
| fw branch / local milestone branches → publishers | A push to `beta` publishes to PyPI or cuts a firmware pre-release. | releases |
| bench evidence / hand edits → GSD records | WINDOWS.md closures, STATE.md frontmatter, SECURITY.md files, gitlinks and the ledger are read by later audits and GSD verbs. | planning records |
| operator decision → accepted risk | Only the operator may turn an open threat into an accepted one. | risk decisions |
