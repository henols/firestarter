this devcontainer because four path literals still point at `.planning/` roots for documents that moved

there. Repairing it is four string literals and is required anyway by the standing never-accept-stale-
citations rule.

needs two measurements on the same tree with the same toolchain. The research measured this baseline on
2026-09-22 at the current HEAD and it must still be re-taken here, because the record has to quote a run
that actually happened inside this phase rather than one taken to inform the plan.

This plan runs in parallel with plan 01: different repositories, no shared file, no shared gate.

Output: a green firmware tree and `205-FLASH-RAM.md` carrying the phase-entry baseline, the stated build
configuration, and the empty rows plan 06 fills.
</objective>

  research's simulated sweep produced an identical delta on all three targets.

D-10's one constraint that measurement CONFIRMS and this plan keeps: quote both Leonardo denominators.
