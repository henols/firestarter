## Flagged planner assumptions (unresolved edges)

Three edges are carried forward **unresolved**, not auto-resolved, because the probe left them
unclassified and an unclassified row must never be auto-resolved with a backstop:

- **CMP-02** — the requirement names a comparison against a constant. No probe category cleanly owns
  "what is the blank byte for a part whose blank state is not the constant this code assumes". The
  plan compares against the same constant the firmware's blank check used and does not widen that;
  a part whose erased state differs is out of this phase's evidence.
- **CMP-07** — the requirement names an exit-code contract. The probe has no category for "a code
  collides with the framework's own usage-error code", which is the real edge here and is recorded
  as an accepted cost in D-10 rather than resolved.
- **CMP-08** — the requirement names two options. D-17 settles the conflict cases the plan can
  enumerate, but the probe did not classify which axis the remainder sit on, so the coverage below
  is what D-17 specifies and is not claimed to be exhaustive.
