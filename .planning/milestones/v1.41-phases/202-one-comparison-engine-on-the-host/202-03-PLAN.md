Never push to `beta` or `main`.

`Fingerprint` is a plain dataclass, so equality is field-wise and `evidence` is a dict whose equality
is insertion-order-insensitive. A whole-object comparison is therefore both achievable and the right
assertion: it catches a field the refactor forgot to populate, which a hand-written field list would
also forget to check.

`hypothesis` is not a dependency of this package and adding it would mean a new CI dependency, with
its own legitimacy gate, for one test. The corpus is parametrised, not property-based — and the five
buckets are threshold-defined regions, so random inputs land in `indeterminate` overwhelmingly.

## Flagged planner assumption (unresolved edge)

The edge probe classified CMP-06 as `unclassified` and it is carried forward **unresolved**, not
auto-resolved. The unexamined question is which axis CMP-06's own edge cases sit on: the requirement
names a classifier whose buckets are threshold-defined, and no probe category (boundary, adjacency,
empty, ordering, precision, concurrency, encoding) cleanly owns "a verdict changes when a ratio
crosses 0.98". The corpus below covers the thresholds that exist in the current implementation
because D-03 requires bit-identical agreement with it; it does not claim to have enumerated CMP-06's
edge space. Surfaced here so the phase verifier sees it rather than inferring coverage.
