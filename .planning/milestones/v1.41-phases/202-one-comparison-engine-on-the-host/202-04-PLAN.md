<objective>
Make the default compare stop the programmer rather than drain it, and answer phase success
criterion 5 in writing instead of leaving it assumed.

This is the phase's one genuinely unplumbed seam. CONTEXT.md describes `_main_phase_read_data` as
reused unchanged; it is not. The chunk callback's return value is discarded at the call site and the
ack is unconditional, so there is no way for the comparison engine to say "stop acking" from inside
the callback. That plumbing is this plan's first task, and it is load-bearing for CMP-04 and for
criterion 5.

D-06 confirms the mechanism works inside the existing protocol with no firmware change: the host
stops acking, the firmware's ack wait times out after one second polled at ten milliseconds, the
outgoing-data routine returns false, and the dispatch loop runs its completion routine, which
disables the chip, zeroes the control and both address registers, sets the command to idle and
restores communication mode. The port is left clean on the error path too — which is precisely the
premise the roadmap got wrong, and why D-07 requires the correction be written down.

Purpose: turn "break at first mismatch" from a diagnostic convenience into an actual saving of tens
of seconds on a 512 KiB part, without ever mistaking the deliberate stop for a fault.
Output: an additive abort seam, the discrimination that keeps it honest, and the written answer.
</objective>
