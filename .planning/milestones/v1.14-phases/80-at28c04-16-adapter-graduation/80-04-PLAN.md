| Boundary | Description |
|----------|-------------|
| host write command → firmware 0x0D handler → adapter → chip | the write path crosses the adapter; a mis-wire (esp. /WE) sends signals to the wrong chip pin — but 0x0D is 5V-only, so the failure mode is non-function, not damage |
| post-write read → verify oracle | the verify board must be trustworthy; Leonardo is the only board not corrupted by the v1.9 read bug |
