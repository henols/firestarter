<objective>
Pin the 2026-06-17 0xA4 write-path desync fix with an explicit host-side regression test (D-07).
The default (no `-b`) write path — which is exactly the path Phase 77's auto-erase graduation makes
the common case — drives `_execute_phase("INIT", ...)`, which emits per-chunk blank-check DATA
progress frames. The fix (`ack_data=False`, commit fcf7974) ensures those DATA frames are NOT acked,
so spurious acks cannot pile up in the firmware RX buffer and desync the MAIN handshake into
`MSG_ERR_EMPTY_INPUT` (0xA4). This test asserts `send_ack` fires exactly once per INIT phase.

Purpose: Implements the D-07 regression guard for ERASE-01 — locks the ack_data=False invariant so
the auto-erase default path (FLAG_CAN_ERASE set in Plan 01) cannot silently regress the 0xA4 fix.
This is the T-77-A4 threat mitigation.

Output: One new regression test in `test_eprom_operations.py`.
</objective>
