## The coverage ceiling this gate enforces

`src/boards/rurp_common.cpp` is compiled by NO native environment -- all six native envs
share the same `build_src_filter`, which admits `src/proms/`, `boards/rurp_serial_utils.cpp`,
`json_parser.c` and `operation_utils.cpp` and nothing else. In native builds
`rurp_read_voltage_mv` is a stub, so every native VPP test exercises the consumer against a
mock. There is no bench coverage and none will be created (D-02).

The mandated correct phrasing, which is this gate's positive-half needle and which must
appear verbatim (modulo whitespace normalisation) in every required target:

> proven by a committed host-side numerical oracle over a stated input grid, bound to the
> shipped C by a source-contract scan; no native and no bench coverage exists.

The named residual risk, which must be STATED and must not be presented as covered:
avr-gcc miscompiling the 32-bit multiply/divide. It is unmitigated by any artefact of this
phase, and is mitigated only by that being AVR's most-exercised path and by the change
reducing rather than increasing codegen complexity.

The six forbidden phrasings are enumerated in `155-VALIDATION.md` under
"The Honest Coverage Ceiling", item 5. They are deliberately NOT reproduced in this plan:
this plan file is itself inside the gate's corpus, and a plan that quoted the list verbatim
would either fail its own gate or force an exemption for itself.

`_scan_file(path)` -- for each paragraph, if it contains any `TRIGGER_TOKENS` entry, count it

line, the needle matched, and the offending normalised paragraph.

the meta repo root derived from `__file__`, three parents up) and `--fw-root PATH` (default:

corpus. Unknown flag or missing value is exit 2.

`main(argv)` -- order of operations:
  1. parse argv (exit 2 on malformed);
  2. resolve the corpus by expanding the globs under the two roots, dropping the three named

     ahead of the anchor check;
  5. run the POSITIVE half: for each `REQUIRED_POSITIVE_TARGETS` entry, a file missing from
     disk is `ERROR:` and return 2; a file present but not containing the normalised
     `CORRECT_PHRASING` is `FAIL:` and return 1;
  6. print `PASS:` naming every file scanned with its in-scope paragraph count, the total
     against the floor, and each required target confirmed, then return 0.
