Build the link-time oracle for DEAD-01 and DEAD-03 -- a fail-closed, non-vacuous,
provably-RED gate that reads the linked ELF's symbol table -- and land it with the four
companions this repo's checker convention mechanically requires, in one commit.

call cannot see the linker: it would pass while the allocator was pulled in by another
translation unit, and it fails open on inlining and renaming, which is exactly what a
size-reduction phase does. Only the linked ELF can witness symbol absence, and no script
or test in either repo has ever invoked a toolchain binary, so this capability is new.

pytest, a committed planted-negative fixture built from the REAL pre-change `avr-nm`
listing, and a deliberate raise of `tests/test_checker_convention.py`'s two floors -- all

`_parse_argv(argv)` -- a manual parser, NOT argparse, matching `check_release_assets.py`'s
house convention (state that choice and its precedent in a comment; note that
`check_erase_no_vpp.py` uses the other precedent and that the manual form is the majority
idiom here). Recognise `--baseline PATH`, `--build-root PATH`, `--nm PATH`, and a repeatable
`--nm-output TARGET=PATH`. An unknown flag or a flag missing its value raises SystemExit(2).

`_resolve_avr_nm(path)` -- return the resolved executable or fail closed with exit 2 naming
the path tried. Never fall back to a bare `avr-nm` on PATH silently; if you allow a PATH
lookup, print which resolution was used.

`_listing_for_target(target, ...)` -- two modes. If a `--nm-output` entry names this target,
read that committed text listing and never invoke the toolchain. Otherwise resolve
`<build_root>/<target>/firestarter_<target>.elf`, fail closed with exit 2 if it is missing
or unreadable, and run `avr-nm` with `NM_ARGS` via list-form `subprocess.run`. Never use a
shell. A non-zero return from the tool is exit 2, not exit 1.

`_scan_listing(text)` -- parse line by line. Split on whitespace; the symbol NAME is the last
field and the TYPE is the field before it. Treat any type other than `U` as a definition and
record undefined entries separately rather than counting them as present. Return the set of
matched heap symbols, the set of matched 64-bit symbols (each with its type and, when the
listing carries one, its size), and which anchors were found.

`main(argv)` -- order of operations, which is load-bearing:
  1. parse argv (exit 2 on malformed);
  2. resolve the target list -- from `--nm-output` entries if given, otherwise from the
     baseline's `avr_targets` keys. An unreadable/unparseable baseline, a non-object baseline,
     or a missing/non-object `avr_targets` key is exit 2. An `avr_targets` object that parses
     EMPTY is exit 1 with the never-vacuous message, copying `check_release_assets.py`'s
     taxonomy verbatim rather than inventing a third code for this case;
  3. never-vacuous guard BEFORE the loop -- zero resolved targets must never print a pass;
  4. per target, obtain the listing and scan it;
  5. report violations UNCONDITIONALLY and FIRST -- if any forbidden symbol was found on any
     target, print `FAIL:` with one indented line per violation naming the target, the symbol,
     its type and its size, then return 1;
  6. only on the otherwise-clean path, check the anchors -- a missing anchor on any target is
     `ERROR:` and return 2;
  7. print the `PASS:` line naming EVERY target compared with its two counts and its anchor
     count, plus the resolved build root or listing source, then return 0.

Guard the entry point with the usual `if __name__ == "__main__": sys.exit(main(sys.argv[1:]))`.
