<objective>
Build the citation extractor and generate the **pre-sweep** citation manifest —
this phase's single non-reconstructible deliverable.

Purpose: D-07 records all citations that target a swept file rather than only the
subset predicted to shift, so Phase 159's oracle can **prove** the others did not
move instead of assuming it. The manifest cannot be rebuilt after the sweep, because
after the sweep the pre-sweep line/text pairs exist nowhere on disk. Per Ruling F a
generator is added: SWEEP-09 names none, but ~10k rows cannot be hand-authored, and
the generator shares its path-resolution rule with the remapper so the same citation
cannot resolve two different ways in the two tools.

Output: `citation_paths.py`, `build_citation_manifest.py`,
`test_build_citation_manifest.py`, the manifest JSONL, and a report carrying the
row count with its producing command and its reconciliation against SWEEP-09's
pre-registered 10,054.
</objective>
