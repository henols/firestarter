<objective>
Sweep `firestarter/test` — 216 hit lines across about 60 files, the largest single
group in the corpus — under D-04's **narrow** treatment only.

Purpose: D-04 is the phase's biggest re-shaping and it exists because of a
measurement. 331 of 636 hits (52%) are in test files, and **no oracle covers any of
them**: the byte-identical `uno` oracle does not include the native tests, and the
host repo has no size oracle at all. The writeup framed the corpus as "provenance
stamped into shipped source"; just over half of it is not shipped source. So the
treatment here is deliberately narrower than in shipped source, and the narrowness is
the mitigation for the missing oracle rather than a convenience.

Output: `firestarter/test` swept narrowly, with IDs retained, and the native suite
plus the dispatch mirror leg re-run against baseline.
</objective>

Sweep the six densest files in the `fw-test` group — about 100 of the group's 216 hit lines —
using **narrow treatment only**, which means exactly three operations and no others:

1. **Tombstone deletion.** A comment describing code that is not there is deleted whole.
2. **Label-only-comment deletion.** A comment that, after removing D-01's tokens and their
   enclosing punctuation, contains nothing but connective punctuation is deleted whole.
3. **Narrative-prefix stripping where a sentence follows.** A `Phase N` / `Plan N` / `Plan N-NN`
   / `Task N` / `PNNN` / `<NNN>-CONTEXT.md` prefix is removed and the sentence that follows is
   left as it stands.

**Explicitly NOT permitted here:** reflowing, rewording, condensing or otherwise rewriting
substantive test commentary. D-04 forbids it and the reason is that there is no oracle to catch
a mistake. If a hit's enclosing comment cannot be handled by one of the three operations above
without rewriting prose, leave the comment alone and record it in the SUMMARY as a
narrow-treatment abstention with its file and line. An abstention is a correct outcome here, not
a failure.

`TABLE-01`, `BASE-02` or any sibling ID from these files. This is the mirror image of plan 07's
strip rule and the asymmetry is intentional; `sweep-corpus-baseline.md` states why so it does
not read as an inconsistency.
