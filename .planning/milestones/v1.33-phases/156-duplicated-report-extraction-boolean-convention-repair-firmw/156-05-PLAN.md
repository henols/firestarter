<objective>
Flip the op-layer completion convention so the nine command wrappers forward the engine's result
instead of negating it, and land the two native test edits the flip forces -- one that fails by
construction and one that would otherwise pass vacuously.

Purpose: OD-2 resolved DEDUP-04 toward removal, so the decline branch of criterion 4 is dead.
The flip is measured size-identical on all three AVR targets in isolation and in composition,
which is what makes it a pure readability change. Three things make it more delicate than it
looks. Two of the engine's six return sites are not literals, and one of them keeps a negation
because the callback it delegates to has its own opposite convention -- so the honest claim is
nine call sites down to one, not elimination. The image is NOT byte-identical even though the
sizes are, so an oracle asserting image identity would go red on a correct change. And the flip
turns one native case red by construction while silently gutting a second into a vacuous pass
that research proved live: Case 25 keeps reporting PASSED while taking one engine call instead
of the four its own comment documents.

Output: six flipped engine returns, nine wrappers forwarding directly, seven corrected comment
locations, Case 24's polarity flipped and Case 25 de-vacuumed with a call-count assertion -- all
in one commit, proven size-identical on all three targets.
</objective>
