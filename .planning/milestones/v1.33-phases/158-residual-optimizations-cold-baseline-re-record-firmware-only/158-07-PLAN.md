## The honest coverage ceilings -- stated, not implied

All twelve appear in every plan of this phase, in every SUMMARY, and in both phase records.

1. **`check_size_baseline.py`, `check_build_warnings.py` and `check_no_heap_or_64bit_symbols.py` are invoked by NO CI workflow** -- every size gate this phase leans on is a **local-run obligation**. A green CI run is not evidence any of them passed. That is LAND-04's whole content.

4. **LAND-06's runtime half is unmeasurable in this milestone** (D-02). The decline rests on a size measurement plus a coverage gap, never on a runtime number.

6. **`sizeof(jsmntok_t)` cannot be asserted in a native test** -- AVR gives 6 B, the host gives 12 B.
7. **The native suite is load-flaky (D-04).** No failure may be attributed to a tree change on N=1, and wall time carries no signal on its own.
8. **A `/tmp` worktree run of `pytest tests/` silently skips 32 cross-repo legs.** Gate-purpose runs happen from `/workspaces/firestarter`.
9. **`lib/jsmn/src/jsmn.h` carries a dead duplicate implementation** that compiles in no translation unit but is live text to a naive grep; it was deliberately left unedited and the source-contract leg is region-scoped above it.
10. **LAND-07's conclusion is a budget argument, not an impossibility argument.**

## The decision this plan executes

**OD-9 as amended by the orchestrator, 2026-08-24.** The original phase brief read "`ROADMAP.md` and
`REQUIREMENTS.md` are NOT edited by the phase", which conflated two different rules. The rule that
stands is **never regenerate** either file -- both are hand-authored for v1.33 and the GSD
requirements and roadmap mutation verbs reformat the whole document. The rule that was over-reach is
"never edit": Phase 157 closed its own requirements at `157-07-PLAN.md` using **scoped `Edit`
replacements only**, with a whole-file `Write` explicitly prohibited and the boundary enforced by
heading-count, line-count and snapshot-diff assertions. This plan follows that template exactly.

The consequence for the other plans is unchanged: plans 01 through 06 still edit neither file, and
every *figure correction* still lives in `.planning/v1.33/158-{before,after}-figures.md`. What this
plan adds is the **pointer** -- a criterion carrying a stale number gets a scope correction naming
the record, so the ROADMAP stops being a source of superseded figures.

**OD-10 restated with the trap named.** The `firestarter` gitlink is not re-pinned by this phase; the
drift predates Phase 154 and Phase 159 owns it. One operational note the record must carry so 159
does not rediscover it: `git commit -- <path>` **discards** a gitlink `update-index`, so whoever
re-pins must drop the pathspec and commit the staged index directly.
