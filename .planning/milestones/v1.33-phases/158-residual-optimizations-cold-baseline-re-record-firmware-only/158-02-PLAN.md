<objective>
Narrow `jsmntok_t` from 8 bytes to 6 on AVR, keep `start` and `end` signed, and pin the signedness
as a machine-checked source contract that fails closed.

Purpose: this is the one criterion in the phase that changes shipped firmware, and it is the phase's
only genuine win -- `−128 B` RAM on every target, and a flash **reduction** rather than the `+30 B`
cost REQUIREMENTS predicted. `NUMBER_JSNM_TOKENS` is 64 and `src/firestarter.cpp` holds a single
`static jsmntok_t tokens[64]`, so two bytes per token is 128 bytes of the Uno's 2 KB. The criterion
also carries a hard constraint that nothing in the tree currently enforces: `start` and `end` must
stay signed, because twelve `-1` sentinel field references across six lines of `jsmn.c` depend on
it, and a future tidy-up to `uint16_t` would break the parser silently. That is the Wave 0 gap this
plan closes.

Output: an edited `lib/jsmn/src/jsmn.h`, a new source-contract gate module, and a recorded ARM
outcome -- built or ceiling-stated. Two firmware commits; no `.planning/` file is written here.
</objective>

11. **Every `file:LINE` citation this phase writes will be newly stale.** Phase 159 remaps them exactly once (D-01, D-05).
