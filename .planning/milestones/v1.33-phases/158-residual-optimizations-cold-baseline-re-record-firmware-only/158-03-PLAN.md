## The honest coverage ceilings -- stated, not implied

All twelve appear in every plan of this phase, in every SUMMARY, and in both phase records.

1. **`check_size_baseline.py`, `check_build_warnings.py` and `check_no_heap_or_64bit_symbols.py` are invoked by NO CI workflow** -- every size gate this phase leans on is a **local-run obligation**. A green CI run is not evidence any of them passed.
2. **But the checker IS executed in CI by its own paired pytest** -- `build.yml:161` `pytest tests/ -v`, ungated, on `push: branches: ['**','!beta']`. LAND-04's honest statement has **two clauses**.
3. **The ARM half of LAND-05 is unverified locally unless plan 02's toolchain install succeeded.** Never claim ARM coverage that was not built.
4. **LAND-06's runtime half is unmeasurable in this milestone** (D-02). The decline rests on a size measurement plus a coverage gap, never on a runtime number.
5. **The algorithm-5 page-boundary path has ZERO behavioural native coverage** -- the only case that executes `flash_5v_page_write_execute` drives a 4-byte write, which never crosses a 64-byte boundary. **This plan proves that by enumeration rather than restating it.**
6. **`sizeof(jsmntok_t)` cannot be asserted in a native test** -- AVR gives 6 B, the host gives 12 B.
7. **The native suite is load-flaky (D-04).** No failure may be attributed to a tree change on N=1, and wall time carries no signal on its own.
8. **A `/tmp` worktree run of `pytest tests/` silently skips 32 cross-repo legs.** Gate-purpose runs happen from `/workspaces/firestarter`.
9. **`lib/jsmn/src/jsmn.h` carries a dead duplicate implementation** that compiles in no translation unit but is live text to a naive grep.
10. **LAND-07's conclusion is a budget argument, not an impossibility argument.**
11. **Every `file:LINE` citation this phase writes will be newly stale.** Phase 159 remaps them exactly once (D-01, D-05).
12. **The `firestarter` gitlink in the meta repo is drifted** -- pre-existing since Phase 154, operator-gated, not re-pinned by this phase.

`test_val_5v_page` case is added. The criterion is discharged by recording: the measured flash cost

**zero behavioural native coverage** of the boundary path as the stated reason. The native case count

test would have been defensible, but it moves the native case count and buys a runtime win that D-02
forbids anyone in this milestone from measuring. The record must state that this alternative existed
and what it would have cost, not merely that the mask was declined.
