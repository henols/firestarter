STEP 4 -- the policy encoding and the two row macros. Define two constants immediately above the

truncation for a bitmask, and it exists because clamping a bitmask to its type maximum would set
every control flag -- naming `FLAG_FORCE`, `FLAG_SKIP_ERASE` and `FLAG_SKIP_BLANK_CHECK` -- which

not "simplify" it back.
