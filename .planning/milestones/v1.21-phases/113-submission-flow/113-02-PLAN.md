<objective>
Create the `firestarter/submit.py` module foundations: the module constants (hardcoded target
repo per D-01, byte thresholds), the SUB-02 recursive PII/path sanitizer, the body/title/URL
builders, and the `gh`-tier detection + shell-out. These are the pure and single-side-effect
units the Plan-03 orchestrator composes.

Purpose: Everything a community report needs to become a safe, self-contained GitHub issue body
without leaking the tester's machine — the whitelist (`to_dict()`) is the guarantee, the regex
scrub is the backstop (SUB-02), the hardcoded repo prevents a misrouted report (D-01), and the
dedup short-hash in the title makes repeats recognizable (D-02, SUB-03 surfacing).

`build_title`, `gh_available`, `submit_via_gh` plus their unit tests behind injected seams — no
PATH, network, or browser touched.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| tester's machine → public GitHub issue | report strings may embed local paths / username / device names — sanitize_dict scrubs them here |
| chip name / free-text reason → subprocess argv | untrusted-ish text must never reach a shell — gh argv is a list |
| CLI → GitHub target repo | must be the maintainer repo, never a fork — SUBMIT_REPO is hardcoded |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-113-01 | Tampering / EoP | submit_via_gh argv | high | mitigate | argv is a LIST to subprocess.run; body via input= stdin; never shell=True — chip name/body never reach a shell |
| T-113-02 | Information Disclosure | sanitize_dict / submitted body | high | mitigate | to_dict() whitelist + recursive regex scrub of home paths, /dev/tty*, COM*, /tmp, username; one test per vector (fails open, A3) |
| T-113-03 | Tampering | build_issue_url query | medium | mitigate | urllib.parse.urlencode(quote_via=quote) percent-encodes all title + body |
| T-113-05 | Tampering | SUBMIT_REPO target | high | mitigate | D-01 hardcoded henols/firestarter_app; no cwd/git-remote inference; browser labels param omitted (Pitfall 1) |
| T-113-SC | Tampering (supply chain) | pip installs | low | accept | Zero package installs — all stdlib + existing rich/click |
</threat_model>
