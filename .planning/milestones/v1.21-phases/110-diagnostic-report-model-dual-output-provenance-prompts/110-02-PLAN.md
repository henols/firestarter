<objective>
Add the provenance layer to `diagnostic_report.py`: the `Provenance`
dataclass, the injectable `prompt_provenance()` prompt component (built on
`rich.prompt` behind overridable `ask`/`confirm` callables), and the
`is_submittable()` predicate. This plan delivers RPT-04 — provenance the
firmware cannot self-report is modelled and collectable here, and a report with
any required provenance field left blank cannot be marked submittable. Per D-04
(mirroring Phase 109's data/rendering split), the model + prompt component +
`is_submittable` predicate are built in THIS phase; Phase 112 only INVOKES
`prompt_provenance()` before the sweep — this plan does not wire the invocation.

Purpose: A beautiful auto-captured report is un-actionable if the shield
revision is unknown, so provenance must be a first-class, submittable-gated part
of the report object — and the shield revision must offer an explicit "not sure"
rather than being wrongly auto-derived from the ambiguous `hw_revision` byte
(the decisive Bug A lesson). Keeping the prompt seam injectable is what makes
the whole component unit-testable without a human or a TTY (CI `--cov-fail-under=70`).

Output: `Provenance`, `SHIELD_REV_CHOICES`, `prompt_provenance`, `is_submittable`
added to `firestarter_app/firestarter/diagnostic_report.py`; the sub-object
composed into `DiagnosticReport`; new test file `tests/test_provenance.py`.
</objective>

<artifacts_this_phase_produces>
This plan (110-02) adds these NEW symbols to `firestarter_app/firestarter/diagnostic_report.py`:

- `SHIELD_REV_CHOICES: list[str]` — enumerated shield-revision options, community-tolerant, NOT a closed hardware whitelist: `["Rev 2.2", "Rev 2.0", "modified Rev 0", "other", "not sure"]` (D-06).
- `Provenance` — `@dataclass`. Fields: `shield_rev: str = ""`, `chip_origin: str = ""` (new/blank vs pulled/used), `owns_eraser: bool | None = None` (UV-only; None when the chip is not UV-EPROM), `pot_touched: bool | None = None`, `pot_note: str = ""`.
- `prompt_provenance(is_uv: bool, *, ask=Prompt.ask, confirm=Confirm.ask) -> Provenance` — collects provenance BEFORE the sweep via the injectable callables. On `shield_rev == "other"` asks a free-text follow-up. Asks `owns_eraser` only when `is_uv`. Asks `pot_note` only when `pot_touched`.
- `is_submittable(p: Provenance) -> bool` — True iff every required field is non-blank; "not sure" counts as filled; `""`/`None` on a required field fails.

Extends (from plan 01): adds `provenance: Provenance | None = None` field to `DiagnosticReport` and a `provenance` section to `to_dict()`/`render()`.
