<objective>
Add the foundational `EpromOperationError.error_code` seam (D-07 / RPT-03): an optional
`__init__` kwarg preserving the firmware `response.id` byte that is discarded today, and
thread it through the single `_raise_for_error_response` chokepoint. This is the smallest,
highest-leverage seam in the milestone — every later per-step result in the sweep (Phase 108
run_plan, Phase 110 report) depends on this attribute existing.

Purpose: Give every EpromOperationError raised from a firmware error response access to the
exact firmware message-id byte (0xA4, 0xBB, 0xB3, ...) that produced it, backward-compatibly.
Output: `EpromOperationError.error_code` attribute; the chokepoint passing `response.id`; a
dedicated unit test file.
</objective>
