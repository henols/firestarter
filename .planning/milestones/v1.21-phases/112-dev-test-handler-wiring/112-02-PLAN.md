entry point that composes the Phases 108–111 building blocks into one runnable
`firestarter dev test <chip>` flow: prompt provenance (TTY) → derive plan
(destructive gate) → run sweep (with the sampler thunk around the write) →
assemble the DiagnosticReport → render to stdout + optionally write dual
artifacts → exit with the 3-way scriptable code.

and a self-contained report. This is pure orchestration over existing services;
zero new logic, zero new dispatch, SAFE-01/02/03 preserved.

all unit-testable via EpromDatabase(skip_local_override=True) + a mock operator.
