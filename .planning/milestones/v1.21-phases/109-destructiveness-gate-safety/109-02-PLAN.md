<objective>
Produce the SWEEP-05 banner DATA from the single Phase-109 `Plan` object and its `run_plan`
results — no rendering. Add an applicable-only N-of-M count helper: M = the steps a
`--destructive` run would actually execute for this chip (supported steps in the derivation
PLUS the applicable entries in `Plan.locked_destructive`, excluding NA/inapplicable slots);
N = the steps this non-destructive run actually executed (ran with any verdict — a ran-but-BAD
step counts as ran; NA/SKIPPED do not). Also add the explicit SAFE-02 verification: a unit
test asserting `run_plan`/`_run_step` route every executed op through `resolve_chip`, set no
VPP, build no raw wire dict, pass no `--force`, and surface a firmware VPP-guard refusal as a
step finding (never a silent retry).

Purpose: The banner ("only N of M tests ran — pass --destructive on a scrap chip for the
rest") gets honest numbers ("3 of 5", the 2 missing being write+verify) instead of inflating
M with never-achievable NA slots; and the orchestrator-only safety property is now asserted by
a test, not merely assumed.
Output: an applicable-only count helper returning (N, M, locked-step list); the SAFE-02
orchestrator-only unit test(s).
</objective>
