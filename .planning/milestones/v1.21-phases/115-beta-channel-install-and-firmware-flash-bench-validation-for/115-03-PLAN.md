<objective>
Make the firmware `.hex` channel publicly reachable: publish a GitHub prerelease
tagged `3.0.0b11` on henols/firestarter carrying the three board `.hex` assets a
bare `firestarter fw -i` downloads. This is the ONBOARD-02 Step-0 gate — the
firmware half of "both channels public."

The publish is IRREVERSIBLE and outward-facing (a public prerelease), so it is
gated behind an explicit operator-authorization checkpoint (D-03). After the
dispatch, positively confirm the prerelease + per-board assets via the app's own
resolver (the authoritative `fw -i` code path) — because `fetch_release_info`
silently falls back to STABLE firmware when no prerelease is found (RESEARCH
Pitfall 2), a green `fw -i` is NOT proof; the resolved tag + asset must be b11.

Purpose: Without this prerelease the community's `fw -i` cannot pull beta
firmware. Output: an external GitHub prerelease; no repo file written here (the
version bump is a CI-side auto-commit on the firmware v1.21 branch).
</objective>
