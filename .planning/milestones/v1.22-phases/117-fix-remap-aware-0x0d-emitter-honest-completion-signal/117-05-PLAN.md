sentence written in this plan and its SUMMARY has code as its subject. The permitted closing claim for
this phase is that the SDP-disable sequence is **emitted** exactly as specified, verified byte-exact by
golden register trace across all four `0x0D` pinouts. Nothing in this phase may be described as
evidence about AT28C silicon state, about whether SDP was actually disabled, or about gh#11's symptom
being gone.

## Why this plan is not parallel with 117-04

Every plan in Phase 117 runs `pio`, and all of them write into the single shared build tree
`firestarter/.pio/build/`. Concurrent PlatformIO invocations in one project corrupt each other's build
outputs, so all five plans are strictly sequential by wave even where their source files do not overlap.
