<objective>

proceeds to the wording review and the community comments.

Purpose: CONTEXT constraints 3 and 7. Without the PyPI half, a tester's `pip install --pre firestarter`

with a PAT that lacks `workflow` scope and GitHub therefore suppresses the `release.published` event
that would trigger `publish.yml`. The workflow's own in-file comment documents it.

Output: a PyPI release, and `.planning/phases/122-…/122-CHANNELS.md` as the committed verification
transcript.

**A green workflow tick is not channel evidence.** The check is a resolution check against the live
index, not a CI status.
