<objective>
Land D-06/D-07: the seventh op string, its membership in both frozensets, and the conversion of `_write_region_for` from guessing to reading.

Purpose: DEVTEST-04's "small part" already exists — `_UV_WRITE_REGION_LENGTH = 256`, top-anchored at `mem_size - 256`. What does not exist is a representation that tells every downstream consumer a run was partial. `dedup_fingerprint` hashes `f"{op}={verdict}:{classification}"`, so a new op string differentiates a partial run from a full one for free, and `count_agreeing`'s fingerprint grouping then makes it structurally impossible for a partial run to cross-agree with a full run toward the N>=2 promotion rule — which is what keeps Phase 114's GRAD-01 no-auto-graduate lock holding end to end.

Two failure modes are being closed at once, both measured: omitting the new op from the live `_DESTRUCTIVE_OPS` frozenset would leave a partial write ungated by a chip-ID mismatch; and `_write_region_for`'s execution-time `algorithm == 0x0B` guess matches only 32 of 301 UV parts, so leaving it in place lets a `full`-shaped unit test keep masking the real path.

Output: `OP_WRITE_PARTIAL`, both frozensets updated, a region-reading `_write_region_for`, and three execution-path tests.

Repo: `/workspaces/firestarter_app` on branch `v1.22-at28c-software-data-protection-lifecycle`.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| chip-ID result → destructive step admission | A mismatched chip must not receive any write, partial or full |
| plan-carried region → operator write call | The region decides how much of a chip is overwritten |
| op vocabulary → dedup fingerprint | The op name is hashed into the fingerprint that keeps partial runs from cross-agreeing with full runs |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-121-21 | Tampering | partial write on a misidentified chip | critical | mitigate | `OP_WRITE_PARTIAL` added to the live `_DESTRUCTIVE_OPS`; proven by a gate test whose load-bearing line is `write_eprom.assert_not_called()`, plus a deliberate-break proof |
| T-121-22 | Tampering | execution layer re-deriving UV-ness and picking the wrong window | critical | mitigate | The guess is deleted, not bypassed; `_PROTOCOL_UV_EPROM` removed; production-path test asserts the region the operator actually received |
| T-121-23 | Spoofing | a `full`-shaped unit test masking a wrong production path | high | mitigate | All region tests drive `run_plan` with the programmer dict shape; no new `_write_region_for(full)` test is permitted |
| T-121-24 | Repudiation | a partial run cross-agreeing with a full run toward N>=2 promotion | high | mitigate | The op name enters `dedup_fingerprint`'s hash, so partial and full runs land in different fingerprint groups — proven in plan `121-07` |
