<objective>
Land the `dev test` contract inversion: zero options, an unconditional always-writes notice, and a UV-only stop-and-ask.

Purpose: this is the plan where `dev test` stops being a diagnostic command and becomes a write test. D-01 and D-03 compose to "every run writes" — UV parts get at least 256 bytes, everything else gets the whole device, TTY or not. The only thing standing between a community tester and a wiped chip is the sentence the command prints, which is why D-04 makes that notice unconditional and first.

Two facts must be owned in-source, not smoothed over. First, `dev test at28c256` — this milestone's own family — writes the whole part with no prompt, because AT28C is EEPROM and an EEPROM write is recoverable via erase. Second, `run_plan`'s N>=2 default means every destructive op runs **twice**, so a non-UV chip receives two full-device writes per invocation; the notice must not say "writes the chip" when it writes it twice.

Output: a flag-free command, two named handler helpers, an extended gate allow-list, and a reworked command test suite.

Repo: `/workspaces/firestarter_app` on branch `v1.22-at28c-software-data-protection-lifecycle`.
</objective>
