<objective>
Land D-02: decide UV-ness once, in the layer that has exact information, and carry the decision on the plan objects.

Purpose: today `_write_region_for` *guesses* UV-ness at execution time from `algorithm == 0x0B`, which matches a measured **32 of 301** UV-EPROM parts — so 269 UV parts silently fall through to the `[0, 256)` window. That was a coverage gap. Under D-01 it becomes a chip-destroying bug: a UV part misread as non-UV receives an unprompted full-device write and is irrecoverable without a lamp. D-02 moves the decision to `derive_plan`, the only place with `full["electrical-type"]`, which is exact at 301/301.

This plan is deliberately behaviour-preserving. It replaces `derive_plan`'s boolean `destructive` kwarg with a three-valued `write_scope`, wires the single production caller to reproduce today's semantics exactly, and adds the carried fields — so the full suite stays green and the contract inversion lands later, in plan `121-09`, where it is visible and tested as such.

Output: a pure `is_uv_eprom` predicate, two new plan-object fields, a three-valued `write_scope`, and a mechanically reworked engine test suite.

Repo: `/workspaces/firestarter_app` on branch `v1.22-at28c-software-data-protection-lifecycle`.
</objective>
