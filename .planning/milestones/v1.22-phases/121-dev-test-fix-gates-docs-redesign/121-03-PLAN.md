Create `tools/check_sdp_capability_invariants.py`, an AST gate over exactly one target file.

**Target resolution and seam.** Define `_HERE = os.path.dirname(__file__)` and `_DEFAULT_SDP_CAPABILITY_SRC = os.path.join(_HERE, "..", "firestarter", "sdp_capability.py")`. Read the env override `FIRESTARTER_SDP_CAPABILITY_SRC`, defaulting to that path — the same shape as `FIRESTARTER_DEVTEST_SRC` and `FIRESTARTER_CMD_ADMISSION_SRC`. Export the default as a module-level name the paired pytest can import for its by-path non-vacuity leg.

**Fail-closed path guard.** If the resolved target is not an existing file, print an `ERROR:` line naming the resolved path to stderr and return 1. Never PASS on a missing target.

**Class 1 — permit-by-default.** Walk the module and flag:
  (a) any `return` statement whose value is a **tuple literal** whose first element is the constant `True`, when that return is not lexically dominated within its enclosing function by a membership test against the name `SDP_CAPABLE_TOKENS`. Scope it to tuple-literal returns per RESEARCH Open Question 5's recommendation: that shape matches `sdp_capability_for_entry`'s single allow exactly and ignores a pure delegating return (`sdp_capability`'s one-line wrapper) without needing a whitelist. "Lexically dominated" here means: somewhere earlier in the same function body (by line number) there is a `Compare` node using `In`/`NotIn` whose comparator is the `Name` `SDP_CAPABLE_TOKENS`, or a comprehension whose `ifs` contain such a compare. Implement it as an ordered walk of the enclosing `FunctionDef` recording the line of the first such membership test, then compare line numbers.
  (b) any bare exception handler — an `ast.ExceptHandler` whose `type is None` — anywhere in the module.

**Class 2 — widenable allow-set.** Flag:
  (a) `SDP_CAPABLE_TOKENS` bound anywhere other than exactly once at module level;
  (b) that single binding's value being anything other than a direct `frozenset(...)` call whose argument is a set/list/tuple **display of string literals only** — reject a comprehension, a generator expression, a call, or a bare `Name` reference;
  (c) any augmented assignment to `SDP_CAPABLE_TOKENS`, any `.union(...)`, `.add(...)`, `.update(...)` or `|=` targeting it, anywhere in the scanned file.

**Fail-closed symbol guard.** Independently of the class buckets, count module-level bindings of `SDP_CAPABLE_TOKENS`. **Reporting.** On any violation print a `FAIL:` block listing every violation grouped by class, each as `path:lineno: description`, and return 1.
