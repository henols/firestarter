| T-121-26 | Tampering | `ladder_state` auto-escalating to a human-gated state | high | mitigate | The ladder test asserts `community-confirmed` is never produced; `build_db_diff` is untouched |

| T-121-28 | Information Disclosure | a fingerprint leaking chip/user detail | low | accept | The fingerprint is a 12-char sha256 slice over chip, protocol, op, verdict and classification — no user-identifying input; `sanitize_dict` remains the PII control on the body itself |
