<objective>
Execute the single operator-witnessed bench session that empirically tests the Phase-98
`0x08` write-path fix on the seated AM27C020 (Leonardo + RURP Rev 2.0). This is the sole
empirical gate for v1.18. Produce the raw evidence — the read-back image, its SHA, N>=3 read
stability, and the VPP reading — into a BENCH-LOG; the finalize plan (99-04) then transcribes
that into the EVIDENCE cell + PROTOCOL-LEDGER.

BOTH outcomes are planned and legitimate:
- GRADUATE: write -b imgA -> read-back byte-exact (readback SHA == imgA SHA), stable N>=3.
- DEFER: the write still programs 0 bits (or the chip proves OTP/dead) -> a clean, documented,
  non-faked deferral recording the failing-vs-fixed signature and the pre-fix read SHA by path.

Purpose: BENCH-01 requires a real silicon write->verify (or an honest deferral); BENCH-02
requires the captured signature + VPP reading + discipline row. Nothing is fabricated; a
tooling-blocked DMM read is recorded as "not measured" with reason (Phase-97 precedent).
Output: readback.bin (graduate branch), the appended readback SHA line, and 99-03-BENCH-LOG.md.
</objective>
