<objective>
Land the firmware half of the belt-and-suspenders fix (D-01) on top of Plan 01's
`DIP32_27C020` pinout: deliberately drive DIP pin 31's bus line to the PGM
program-active level (= VIL, hold LOW — Q1 RESOLVED in 98-RESEARCH; static-high
yields HIGH at the socket with no inversion, so it cannot express PGM=VIL) and hold
it across the per-byte CE pulse in the program window, so pin 31 is an asserted
control (not coincidentally-VIL via the address bus — the verifier's RC-1 caveat).
Plan 01's pinout already took pin 31 OFF the address bus; this plan is the vehicle
that actually asserts PGM=VIL. Extend the existing per-buffer `CTRL_VPP_P1_ENABLE`
hold (already 90% built in `program_mismatched_bytes`) to cover the per-byte CE
pulse as the "suspenders." Gate ALL PGM/P1-hold behavior on
`protocol == 0x08 && pins == 32 && mem_size <= 262144` so it is unreachable for any
512K/1M A18 user — the firmware belt of the D-04 alias guard. No new wire field is
added (D-03 honored — Q2 RESOLVED: existing protocol/pins/mem_size/bus_config fields
suffice). Cover the corrected path with native tests (recording-based PGM assertion +
a mandatory failure-case/mismatch test, the P89 CR-01 lesson) and keep the
0x07/0x0B/chip-id golden traces byte-identical, re-pinning only the 0x08 trace if it
legitimately changes.

Purpose: FIX-01 (program pulse asserts the correct signals) + FIX-02 (golden
regression discipline + native coverage incl. failure-case) + the firmware side of
the SAFE-02 invariant. This is a blind fix — it must NOT over-claim bits will flip
on silicon (Pitfall 6 / the verifier's pin-31-already-VIL caveat); the empirical
gate is Phase 99.

Output: gated PGM hold-LOW in firmware; extended P1-hold across the CE pulse;
corrected-path + gate-exclusion + mismatch native tests; re-pinned 0x08 golden
trace (if changed) with reverted 0x07/0x0B/chip-id traces.
