<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| host CLI → firmware (serial `write`) | The program attempt crosses into the firmware program pulse asserting VPP at the socket. SAFE-01 owns this — the procedure must use plain dispatch, never relaxing the over-voltage guard. |
| firmware control register → shield → socket (held-rail proxy) | `dev reg -f` statically routes the VPP rail to socket pin 1; a wrong held value could mis-route ~13V. Mitigated by the Plan-01-pinned host-namespace values + the cleanup reg-clear. |
| operator DMM ↔ live socket | Operator physically probes pins carrying up to ~13V; the held-rail proxy makes this a steady-state read, not a live-pulse chase. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-97-SAFE-01 | Tampering | over-voltage VPP guard + host `resolve_chip` | mitigate | The write attempt uses plain `firestarter write` — no --force, no -b-skip, no escape hatch (D-07); over-voltage stays ERROR-blocked. Confirmed by Plan 01's SAFE-01-PREFLIGHT note. |
| T-97-OVERSPEND | Denial of Service (irreversible silicon) | seated UV AM27C020 | mitigate | Exactly ONE program attempt at 0x000000 (D-01, Pitfall 7); check_signature.py asserts pristine pre==post SHA when 0 bits flip; no multi-byte image. |
| T-97-RAILHELD | Tampering | held VPP rail | mitigate | After the pin-1/pin-31 proxy reads, `firestarter dev reg 0 0 0 -f` (or power-cycle) clears the held rail — the rail is never left energized. |
| T-97-FAB | Repudiation | measured signature fields | mitigate | All fields recorded verbatim from captures/operator DMM; "not measured" used where a reading is unavailable; D-02 forbids fabrication. |
| T-97-UNDERVOLT | Information Disclosure (false verdict) | VPP-low WARNING-only path | mitigate | The pin-1 DMM (12.5-13.0V pass band) + ADC cross-check is mandatory before any write verdict is trusted (Pitfall 2 / D-07) — a low pot silently under-programs with no error. |
