<objective>
Delete the firmware half of the frame-vector apparatus and re-record the native size baseline it
moves — in one cold capture, one commit.

Purpose: D-08 retires the whole apparatus across both sub-repos; this is the firmware side. The
native suite is registered in both pinned environments, and the size comparator asserts case counts
with equality, so removing the suite reddens the comparator until the counts move — and reddens the
firmware's own python suite, whose clean-fixture leg asserts the current figures appear in the
checker's output. D-21(b) therefore makes the deletion and the re-record one cold capture, not two.
Four CI steps across two firmware workflow files invoke the vector generator and none of them is
named by any decision; missing them turns firmware CI red on every branch and on every beta push.

Output: a firmware tree with no frame-vector apparatus, a native baseline re-recorded from a fresh
capture, two re-captured fixtures, and green firmware gates.
</objective>
