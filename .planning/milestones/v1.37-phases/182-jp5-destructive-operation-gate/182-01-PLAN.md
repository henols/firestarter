<objective>
Ship the socket-pin-1 hazard gate end-to-end and make SAFE-01's own wording the predicate.

Purpose: the SAFE-03 trace resolved D-05 against the operator's stated expectation. The pin-map fix
moves VPP off socket pin 1 but puts A19 there, and on Rev 2.x the A19 line and the VPP-enable line
are the same physical control bit (0x08). So a write still drives 12.75 V onto the part's A19 pin
above address 0x7FFFF while JP5 is bridged. The gate is owed, scoped to write and erase.

Output: the DIP32_27C801 layout in pinouts.json; a new firestarter/jp5_gate.py policy module; a
typed refusal in exceptions.py; an unconditional operator-layer refusal in write_eprom and
erase_eprom; an interactive prompt at the two CLI bodies; and tests/test_jp5_gate.py.
</objective>

(b) firestarter/jp5_gate.py — new pure-policy module. Copy the five properties of
serial_comm._validate_hardware_revision: no I/O, no environment read, early return on out-of-scope,

damage and the one legitimate escape. Symbols, exactly:

SOCKET_PIN_1_BUS_LINE — derived as pin_conversions[32][1] imported from firestarter.database, never
a literal 21. One source of truth per layer: do not re-derive socket-pin-to-bus-line arithmetic here.
Measured this session: bus line 21 is reachable from exactly one socket position, a 32-pin part's
pin 1.

GATED_ADDRESS_BIT = 19 — SAFE-01's own address bit. The comparison is >=, legitimate here because
address-bit index is a genuinely ordered scale: it gates A19 and any higher bit a future part might
place there, and exempts the A18 case. Measured against the shipped database: 8 rows sit at bit 19
after the regeneration, 255 rows sit at bit 18 (DIP32_SST39SF040, algorithms 5, 6, 14 and 41), and
none above 19. So this gates exactly the eight 8 Mbit rows and changes behaviour for no other
shipped part.

DAMAGE_CAPABLE_OPERATIONS = frozenset of write and erase — the D-06 scope, taken from the SAFE-03
trace's firmware assert sites, not from inference.

socket_pin1_address_bit(bus_config) — returns the address-bit index socket pin 1 carries, or None.
Reads the bus list out of bus_config and returns its index of SOCKET_PIN_1_BUS_LINE when present.
Returns None for a falsy bus_config, a missing bus key or an empty list. The bus list is an ordered
A0..An list, so the index IS the address bit: use index lookup, never membership alone, per D-01.

is_affected(bus_config) — True when the bit is not None and is >= GATED_ADDRESS_BIT.

hazard_text(chip_name, operation, address_bit) — the operator-facing message. Checkable against the
silkscreen, which is unconditional: "JP5: Cut for ROMs with A19 on P1". State what the part has (an
address line at that bit on socket pin 1), what the operation does (drives that pin from the 12.75 V
programming rail once the address crosses the bit), that JP5 ships bridged by default (its KiCad
footprint is a Bridged SolderJumper) and that the tool cannot read its state, that JP5 must be cut,
and that the only escape is answering yes in an interactive run. Do NOT reproduce "Open for 32 pin
ROMs, Closed for 28 pin ROMs" — two-state language on a three-pole jumper, per D-10. Do NOT claim to
know JP5's current state.

require_acknowledged(chip_name, bus_config, operation, acknowledged) — the unconditional
operator-layer guard. Returns None when the operation is not in DAMAGE_CAPABLE_OPERATIONS. Raises
