## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| approved body on disk → public issue comment | The moment of publication. Every watcher of a public repository receives it; it can be edited but never un-seen. |
| operator's approval → the agent's act | The gate is the only thing standing between a drafted body and a public statement, and auto-mode is the one way it can be bypassed. |
| this issue → the other five | An over-broad `gh` invocation or a loop with a wrong bound could touch an issue this gate never approved. |
