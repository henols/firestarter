<objective>
Stop two firmware files asserting things that are not true: that a deleted checker machine-reads
`PROTOCOLS.md`, and that a 13-row C table has one row per entry of a 12-entry Python set.

Purpose: CLAIM-01's firmware half and D-10's narrow correction. `PROTOCOLS.md:11` is one of the two live
references CLAIM-01 names by line. Its paragraph also instructs readers to preserve a table shape for a tool
that does not exist, bounded by a claims-region marker the file does not contain — D-09 replaces it with one
honest line rather than a silent erasure, on the precedent meta `CLAUDE.md:12` already set for the same
retirement. Separately, the comment above `kAllProtocolFamilies` claims one row per `KNOWN_PROTOCOLS` entry,
which is false in three places; D-10 deletes that clause and nothing else, under a project rule that makes
writing a replacement comment unavailable.

This is expansion work on a different repository from the phase's tracer (`184-01`), sharing no file with it.

Output: a `PROTOCOLS.md` that says what is actually true about who reads it, and a C comment that has lost
exactly one false clause and gained nothing.
