<objective>
Build the check that makes a `ScanPathEntry` naming a guard file that does not exist UNWRITABLE, watch it
fail on the real rotted entry, and let that failure be what removes the entry.

Purpose: CLAIM-09 exists because nothing detected any of CLAIM-01, CLAIM-02 or CLAIM-03. The inventory in
`tests/scan_paths.py` has carried a handoff to `tools/wiki/dispatch_mirror.py` since 2026-08-31, two days
before that file was deleted, and four tests iterating the same inventory never noticed — because
`resolved_by` is prose that nothing resolves. D-11 closes it by construction rather than by discipline: the
field is restricted to bare filenames present under `firestarter_app/tests/`, so the defect becomes
unwritable instead of merely undetectable. D-13 requires the guard to be proven on the actual defect before
the synthetic one, and forbids a hand-delete first.

This is the phase's TRACER slice: it wires the whole path this phase touches — the inventory data module,
the guard test that reads it, and the `pytest` invocation that decides whether the repository is telling the
truth — end-to-end, on one real defect, before any other plan expands out from it.

Output: a fifth test in `tests/test_scan_paths_resolve.py`, an inventory with the rotted entry gone, a floor
anchored to a reason rather than a census, and captured RED-then-GREEN evidence for four separate
violations.
</objective>
