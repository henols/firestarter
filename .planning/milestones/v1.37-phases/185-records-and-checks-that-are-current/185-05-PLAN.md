<objective>
Repair the two self-comparing verifications in `tools/catalog/sync_to_subrepos.sh`, and prove the repair by
watching it go red on a planted break before restoring the tree.

Purpose: folded scope, D-14. Each of the two verifications runs a `diff` of a path against itself, then
prints a success line for a property never tested, with no `else` branch. Because the tautology sits inside
an `if` condition, `set -e` never fires and no failure can ever be observed. It is the same defect class as
the workflow plan 185-06 retires — a check that cannot fail — sitting in the repository's only sync tooling,
immediately after the code-generation calls it purports to verify.

It folds in now rather than staying deferred because retiring that workflow removes the only CI check on
cross-repo catalog identity, which makes this script the sole remaining mechanism asserting it. Repairing
these two directly narrows the residual gap plan 185-06's record is required to disclose.

Output: a script whose two verifications compare distinct operands and can exit non-zero, with a
transcribed red observation and a paired green.
</objective>
