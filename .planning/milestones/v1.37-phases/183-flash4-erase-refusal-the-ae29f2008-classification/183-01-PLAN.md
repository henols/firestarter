<objective>
Price all three candidate refusal mechanisms against real firmware flash, on all three AVR targets, and
create the firmware milestone branch the rest of this phase needs.

Purpose: SAFE-07 and activation decision D-3 both require the firmware-flash cost of SAFE-06 to be
MEASURED before the mechanism is chosen. D-01 widens the pricing from SAFE-07's two named candidates to
three by adding the host pre-flight policy gate. D-11 states explicitly that the measurement must not be
skipped on the strength of a projection, and D-16 fixes the procedure as a cold build of `uno`,
`uno328pb` and `leonardo`.

This plan contains NO implementation task. The phase's tracer slice is `183-03` Task 1, and it depends on
this plan precisely so that the mechanism is priced before it is chosen. Nothing here is a horizontal
foundation layer — Tasks 2 and 3 produce measurements, and Task 1 produces the git branch every later
firmware task commits onto.

Output: a per-target pricing table for M1/M2/M3, the recorded toolchain versions, and a firmware
submodule sitting on the v1.37 milestone branch with a clean working tree.
</objective>

written down — so the contract is enforced by convention and code review only. The fourth sibling is the
point at which that debt should be re-costed against D-03.
