<objective>
Run the Tier-3 HIL cell for the eprom family (VAL-01) on Leonardo with the on-hand W27C512,
recording a real verdict (PASS or FAIL) plus a passing negative control.

W27C512 is an electrically-erasable EEPROM at 12V VPP, 28-pin, `support_status: supported`
(D-04 — NOT a UV-EPROM; the ROADMAP "UV-EPROM 0x07/08/0B" label is `configure_eprom`
handler-family shorthand). This plan invokes the existing `dev validate-family` runner (D-15,
reuse-not-rebuild) — it does NOT write any new read/write code — and records the emitted cell as
VAL-01 Tier-3 evidence. Per D-12, a FAIL is a valid outcome that routes the divergence to Phase 74.

Purpose: Produce real bench evidence for the configure_eprom family on the milestone's only
valid-PASS board (Leonardo, D-14). Output: a Tier-3 eprom cell (verdict + authoritative pass_type
+ evidence_sha) plus a recorded passing negative control.
</objective>
