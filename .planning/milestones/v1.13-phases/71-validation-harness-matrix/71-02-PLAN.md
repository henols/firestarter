<objective>
Create the AUTHORED validation matrix (D-01): a single app-owned JSON spec enumerating all 6
families and their algorithm IDs, plus a deterministic codegen script that emits a committed
C++ header for the native suites — mirroring the established `tools/catalog/codegen.py` shape.
Keep this authored INPUT strictly distinct from the emitted RESULTS artifact (D-02), which is
produced later by the Tier-3 runner (Plan 06).

Purpose: HARN-02 requires one declarative matrix that drives BOTH the native suites (via the
generated header) and the host bench runner (which reads the JSON directly). This plan stands up
the input + codegen half. The codegen dependency (spec → header) must land before the native
suites that consume it (Plan 04).
Output: authored JSON, codegen script, committed generated header, schema + drift tests.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| authored spec → codegen | JSON spec is the only input to header emission; validated before emission |
| codegen output → firmware test build | Generated header is committed; consumed read-only by native suites |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-71-INPUT | Tampering | validation_matrix_spec.json fed to codegen | mitigate | validate_spec() raises ValueError on schema violation BEFORE any emission (V5 Input Validation, codegen.py pattern); main() returns nonzero on invalid spec |
| T-71-DRIFT | Tampering | committed validation_matrix.h diverging from spec | mitigate | Drift gate test re-runs codegen and asserts byte-identical output; CI fails on un-regenerated edits |
| T-71-CONFUSE | Tampering | authored input confused with emitted results | mitigate | Distinct names: validation_matrix_spec.json (underscore, tools/) vs validation-matrix.json (hyphen, emitted by runner) — Pitfall 4 |
| T-71-SC | Tampering | npm/pip/cargo installs | accept | No package installs; reuses stdlib json + present pytest/ruff substrate (D-10). No legitimacy checkpoint needed. |
</threat_model>
