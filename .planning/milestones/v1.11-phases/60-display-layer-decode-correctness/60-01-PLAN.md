<objective>
Land the six interrelated display-decode edits that make `firestarter info` derive the
chip Type, erasability, VPP display, and flags description from the database's
`electrical.type` ground truth instead of keying solely on `protocol_id`. Surfaces the
Phase 59 `cca7d62` EEPROM reclassification (W27C512, SST27VF512, SST27SF512, W27C257, …)
to the operator while leaving genuine UV-EPROMs (2764, 27C256, M27C512) unchanged.

Purpose: Both an EEPROM (W27C512) and a UV-EPROM (2764) carry identical
`programming.algorithm`/`protocol_id` = `0x07`; only `electrical.type` distinguishes them.
The current display keys on `protocol_id` and collapses both into "UV-EPROM / MTP-Flash".
This plan fixes D-01 (Type label), D-02 (Can be erased), D-03 (erasable bit), D-05
(verified marker), and D-07 (0x10 collision + VPP gate + flags pruning). D-03 and D-07's
0x10 reconciliation MUST land atomically — once D-03 sets bit 0x10 for EEPROM chips,
`_interpret_flags` would otherwise render the opposite meaning.

Output: edited `database.py` + `ic_layout.py`; new unit + synthetic + parametrized smoke
tests in `tests/test_eprom_database.py` and `tests/test_eprom_info.py`.

HOST-ONLY. All edits land in the `firestarter_app/` sub-repo on branch
`v1.11-infoic-decode-correctness`. No firmware changes. No edits to `chip_database.json`.
</objective>
