<objective>
Run the one gate the database pulse cannot reach. A 4096-byte write at `--pulse-us 4688` makes each block's
per-byte loop run about 5 s against the firmware's 1000 ms emission interval, which is where D-10's Claim B
becomes observable, and it crosses the 4687 µs residual-gap threshold so its advertised CAP-03 budget exceeds
the old 120 s fallback. One run therefore discharges three inherited items at once. A companion 4096-byte run
at the database pulse then makes D-12's A1 per-pulse-overhead figure genuinely derivable rather than a
hand-wave.

Purpose: RQ-4 proved D-10's literal claim is arithmetically unreachable at the database's 100 µs pulse — the
emission is time-keyed at 1000 ms with `last_emit_ms` re-initialised per block, and a 1024-byte block takes
roughly 400 to 700 ms. Rather than leave 143 H4 undischarged, the phase spends about 25 s of bench time to
reach it properly.

Output: Gate 3's authorization recorded verbatim, both run subsections with their command lines as headings,
the Claim B verdict, both D-12 records, and the A1 derivation with its error sources stated — or its explicit
non-discharge.
</objective>
