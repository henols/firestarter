## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator pot → firmware VPP guard | The guard is the only thing standing between an out-of-band rail and a damaged part; `--force` converts its abort into a warning |
| host command flags → firmware behaviour | `-b` means the opposite thing on `erase` and on `write`, and `--skip-erase` silently produces a false green |
| chip prior content → the record | Once the erase fires, anything not already captured is gone |
