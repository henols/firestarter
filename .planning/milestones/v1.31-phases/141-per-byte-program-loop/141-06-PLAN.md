<objective>
Close LOOP-02's and LOOP-07's own **wording** with a committed source-scan gate. The D-13 inventory
proves the write path's predicate *shape* moved; it does not prove the four constructs LOOP-02 names by
identity are gone, and no existing gate proves LOOP-07's claim is **global**.

LOOP-02 names four things to remove: `program_mismatched_bytes()`, `verify_and_update_mask()`, the flat
`NUMBER_OF_RETRIES` block loop, and the adaptive `pulse_delay = org + org*retries/20` growth. LOOP-07
claims **no call path** can reach `delayMicroseconds()` above its 16383 us ceiling, and per **D-06** the
complete over-ceiling-capable inventory is exactly two sites — `memory_set_data`'s program pulse and
`eprom_internal_erase`'s erase pulse, both taking the unclamped `handle->pulse_delay`. A pure-absence
assertion is vacuous on its own (the call could have been deleted rather than rerouted), so each absence
leg is paired with a **positive count**.

Two recorded traps this module must avoid by construction:

- **A gate that quotes its own forbidden tokens matches itself** and can never pass. Build every needle
  by string concatenation, as `tests/test_vpp_seam_manual_on_every_board.py:447-468` does for
  `pytest.skip` and `mark.skipif`. This is the single most likely way this gate ships broken-but-green.
- **The rewritten `eprom.cpp` will very plausibly carry a comment** saying it replaces the former
  `NUMBER_OF_RETRIES` block loop. `test_params_table_has_no_second_selector`'s own docstring records the
  same problem ("the real file's own docstring uses the English word 'switch' twice while explaining that
  it contains none"). Strip comments before asserting absence, with a stripper that replaces each stripped
  span with whitespace **of the same shape** so line numbers survive exactly.
