<objective>
Install the ARM toolchain, compile the `py32f071` target against this milestone's code, and record the observed
outcome under exactly one of three named arms — because gh#15 box 9 says *all firmware targets build
successfully* and the operator chose to grade it on an observation rather than on an inference.

Purpose: research measured that **neither repository's CI has ever run any v1.31 code.** The firmware's remote
milestone branch sits at the end of Phase 138 and the host's at the branch point, so every commit from Phase
140 onward — the parameter table, the per-byte loop, the VPP consolidation, `eprom_budget`, the CAP ports, the
two Phase-145 debug fixes — exists only locally. Two v1.31 commits *registered* new translation units into the
ARM CMake manifest without ever compiling them for ARM. Box 9, the ledger's `never run` evidence tier and both
release bodies all depend on which of those two things is true, and the honest way to find out is to build it.

Output: `146-ARM-BUILD-RECORD.md`, the raw logs under `arm-build/`, and — only in the RED arm — one backlog
stub in `ROADMAP.md`.
