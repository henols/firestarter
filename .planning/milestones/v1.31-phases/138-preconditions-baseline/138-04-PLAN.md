<objective>
Capture the **host** half of PREP-03's pre-change baseline: the full `firestarter_app` suite's collected,
passed, skipped and failed counts, measured on the v1.31 branch's own tree, under the CI-parity
interpreter, with every figure attributed to the command and the tree that produced it.

Purpose: TEST-03 in Phase 144 makes a CI-scoped claim about the host suite. Without a base measured under
the same interpreter CI uses, that claim rests on an unmeasured foundation — and this project has been
burned by exactly that: the devcontainer's ambient Python 3.12 masks the app's py39/3.11 CI, and a
measurement taken in the wrong tree or with a doubled `-q` silently produces the wrong number or no
number at all.

Output: `138-04-HOST-BASELINE.md`.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| interpreter selection to CI claim | The devcontainer's ambient Python is not the interpreter CI uses; a figure measured with it is not a CI-parity figure |
| worktree branch to recorded figure | The app worktree can sit on a third branch entirely, so a figure measured in place may describe a tree nobody named |
| editable install to import resolution | The package is installed editable, so a run launched from elsewhere can import a different copy than intended |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-138-17 | Spoofing (of provenance) | a host count attributed to the v1.31 base but measured on another branch | mitigate | HEAD is asserted equal to plan 01's recorded base SHA before the suite runs, and the SHA is recorded beside every figure |
| T-138-18 | Tampering (of the record) | a py3.12 figure presented as CI parity | mitigate | The interpreter is pinned explicitly and its `--version` is asserted to be a 3.11 series, with the string recorded in the artifact |
| T-138-19 | Repudiation | a suppressed count line producing a figure recalled rather than read | mitigate | `-o addopts=""` is mandatory and asserted by an acceptance criterion; the verbatim tail is committed |
| T-138-20 | Tampering | silently stashing a tracked app-repo modification to switch branches | mitigate | Fail closed on any modified tracked file and record it instead of discarding it |
| T-138-21 | Elevation of privilege | an unintended commit or push in the app repo | mitigate | The plan writes no file inside the app repo; `git log --oneline -1` is asserted unchanged |
| T-138-SC | Tampering | package-manager installs | accept | No package is installed; the pre-existing `.venv/ci-replica` environment is used as found, so no `## Package Legitimacy Audit` is required |
</threat_model>
