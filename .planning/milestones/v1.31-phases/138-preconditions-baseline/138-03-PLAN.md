<objective>
Build the instrumentation that makes "before" measurable: a third **opt-in** stub layer that records
`delay()` / `delayMicroseconds()` interleaved with the existing ordered strobe stream (**D-02**), a
comparator over the merged stream, a dedicated fourth native environment, and a Unity suite that drives
the **current, unmodified** 27C program loop for all three protocols on a small synthetic block
(**D-01**, **D-03**).

Purpose: neither existing recorder can see time. `HOST_STUBS_RECORD_BUS` records `(reg, data)`;
`HOST_STUBS_REAL_REGISTER_UTILS` records ordered `(kind, pin, value)` strobes. v1.31 changes pulse
**width** and pulse **count** and adds an overprogram pulse — a strobe-only trace is blind to every one
of those, and Phase 144's TEST-06 ("every changed strobe attributable to a named decision") would cover
far less than its wording implies. This plan captures the stream and proves it deterministic; plan 05
freezes it.

Output: the timing layer, the fixture header's machinery (no frozen arrays yet), the suite, the env, and
a record of the measured entry counts.

**Fence:** this plan edits **no** write-path source. `src/proms/eprom.cpp` and `src/proms/memory.cpp`
are read-only here. The program pulse is `memory.cpp:329` `delayMicroseconds(handle->pulse_delay)` — not
`eprom.cpp:283`, which is the *erase* pulse (CONTEXT.md's citation is wrong on this point and
RESEARCH.md corrects it). Both files are on the write path and both are off limits.
</objective>
