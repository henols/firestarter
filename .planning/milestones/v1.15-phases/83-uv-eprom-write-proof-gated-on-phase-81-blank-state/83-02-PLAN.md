<objective>
Bench-prove the WRITE PATH of the read-stable BLANK UV-EPROM ST M27C512 (0x07, 64KB), with
the operator making the irreversible spend-vs-preserve decision live at the bench before VPP
is applied. A blank UV part takes a full deterministic image cleanly, so this is the strongest
UV write proof (every address line + bit pattern exercised), verified by a read-back SHA match
on the trusted Leonardo read.

Purpose: satisfies UV-01 (non-destructive-first: blank-state re-confirmed before write),
UV-02 (explicit per-chip bench spend authorization before VPP), UV-03 (spent-part write proof
= full known image since blank, verified by read-back SHA), and UV-04 (recorded read + decode
validation plus write proof if spent) for ST M27C512.
Output: an EVIDENCE.{md,json} ST M27C512 row capturing the spend decision, the write op, the
image + read-back SHAs, the N≥3 read oracle, the negative control, and any anomalies.
</objective>
