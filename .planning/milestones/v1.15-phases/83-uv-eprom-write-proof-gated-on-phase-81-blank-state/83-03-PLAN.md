<objective>
Bench-prove the WRITE PATH of the read-stable NOT-BLANK UV-EPROM AM27C020 (0x08, 256KB) via a
full all-0x00 wipe (the only legal 1→0 transition on a UV part without an eraser), with the
operator making the irreversible spend decision live at the bench; then record the GRAD-03 /
2516 deferral to Phase 84 explicitly and update the REQUIREMENTS/ROADMAP tracker so the
reassignment is documented, not silently dropped.

Purpose: completes UV-01/02/03/04 for AM27C020 (read-back SHA == SHA(all-0x00) on the trusted
Leonardo read), and closes the GRAD-03 requirement's Phase-83 obligation as a recorded,
documented handoff to Phase 84 — the entire 2516 (write/preserve/re-read) is deferred per D-01
because its read path is unstable (Phase 81 ANOMALY), so a 2516 write in Phase 83 would risk a
vacuous PASS on an irreplaceable part. The D-08 PASS bar for the Phase-84 2516 proof is
pre-recorded so Phase 84 inherits it without re-discussion.
Output: the AM27C020 EVIDENCE.{md,json} row, a GRAD-03/2516 Phase-84 handoff record in
EVIDENCE + REQUIREMENTS + ROADMAP, and the Phase 83 evidence section finalized.
</objective>
