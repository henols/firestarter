<objective>
Ship the bounded D-11 firmware VPP-skip fix: when the operation does not drive VPP
(`CMD_READ` / `CMD_BLANK_CHECK`), skip the VPP regulator-enable + measurement + ERROR/WARNING
inside `eprom_generic_init`. This clears the chip-1 `18.8V > 12.0V` read refusal and the benign
`VPP is low` read warnings (per the operator's 2026-06-24 directive, folded todo
`2026-06-24-skip-vpp-error-and-warning-checks-when-vpp-unused-on-reads.md`). It does NOT touch the
0x0B shared-pin driving, the 0x08 write/VPP path, or flash4 (those are RCA-and-defer, D-31/D-32).

Purpose: removes the spurious VPP gate on non-VPP operations (FIX-01, in-posture firmware fix) so
the Phase-84 bench can re-read the 2516 without the boot-time refusal, while keeping the
over-voltage block intact for every write/erase/chip-id path (over-voltage hazard mitigation).
Output: a fenced VPP gate in `eprom.cpp`, a native dispatch test proving positive + negative
behaviour, both committed on the firmware `v1.15-…` branch.
</objective>
