<objective>
Demonstrate that the rulesets Phase 172 created actually reject a direct push to `main`, and that
they do not reach past the default branch — by performing the push and recording what GitHub says,
not by reading the configuration back.

before a byte reaches GitHub — demonstrated in RESEARCH.md against a bare repo with **no rules at
all**. Both would record a rejection and attribute it to a ruleset that was never consulted.

Output: three per-repository probe transcripts, a before/after ruleset pair proving the probe
changed nothing, and one verdict record that says PASS or INCONCLUSIVE per repository on the
strength of the rejection text.
