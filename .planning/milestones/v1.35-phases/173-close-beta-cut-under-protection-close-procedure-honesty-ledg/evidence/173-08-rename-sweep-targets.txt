=== 173-08 Task 3: Backlog 999.9 rename-sweep target list (criterion 4's second half, made mechanical) ===

Backlog 999.9 (gh#2) renames two of the three repositories: firestarter_prom -> firestarter,
firestarter -> firestarter_fw. firestarter_app is not renamed but is one of the three repository
names this milestone's links name, so it is one of the three search targets below alongside the
other two.

Scan method, stated so this record is reproducible rather than narrative:

  /usr/bin/grep -coP '(firestarter_prom|firestarter_app|(?<![A-Za-z_])firestarter(?!_))' <file>

run once per tracked file, over three separate `git ls-files` listings (one per repository working
tree: the meta repo at /workspaces, firestarter, firestarter_app), NEVER the `grep` on PATH. The
devcontainer's PATH `grep` is ugrep and honours `.gitignore` by default; plan 172-09 measured this
directly over an unrelated pattern and got 0 matches under PATH `grep` against 38 under GNU grep
over identical paths (evidence/172-09-legacy01-final.txt) — this plan uses the same GNU-grep-over-
git-ls-files discipline for the same reason: a scan that silently declines to look is a false green,
not a real one. Case-sensitive, lowercase only, deliberately: it targets the repository-slug shape
(`henols/firestarter...`, pip package names, gitlink remotes, file paths) rather than every English
use of the capitalized project name "Firestarter" in prose, which is not itself a rename target.
The `(?<![A-Za-z_])firestarter(?!_)` branch matches bare `firestarter` only where it is not part of
`firestarter_prom` or `firestarter_app` (or any other `firestarter_something` token), so the three
counts below do not double-count each other.

git ls-files was run separately inside each of the three repository working trees (meta at
/workspaces, firestarter, firestarter_app) rather than through .gitmodules gitlinks, so each
listing is that repository's own tracked-file set, uninflated by the other two.

== Reproducing this scan ==

  cd /workspaces
  for repo in . firestarter firestarter_app; do
    git -C "$repo" ls-files | while IFS= read -r f; do
      c=$(/usr/bin/grep -coP '(firestarter_prom|firestarter_app|(?<![A-Za-z_])firestarter(?!_))' "$repo/$f" 2>/dev/null)
      [ "${c:-0}" -gt 0 ] 2>/dev/null && echo "$repo/$f: $c"
    done
  done

No file this scan produced was edited; this is a read-only inventory of what Backlog 999.9's
rename would invalidate, not a repair of any of it — REQUIREMENTS.md places the rename itself
out of this milestone's scope, and this record exists so the sweep it hands off to is
mechanical rather than a re-read of every file from scratch.
