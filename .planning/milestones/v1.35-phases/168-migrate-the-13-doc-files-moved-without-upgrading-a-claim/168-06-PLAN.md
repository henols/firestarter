<objective>
Repair every reference in the `firestarter_app` repository outside its test tree that points into a
`doc/` directory — deleting the ones that are comments, repointing the ones that are docstrings, and
rewriting the ones a user actually sees at runtime.

Purpose: criterion 2 says *no* file in either repository links to a path beneath `doc/`. Three of
these sites are not documentation hygiene at all: two are strings the application prints to an
operator's terminal and would, after this phase, name a file that does not exist; and one is a third
lockstep-maintenance rule that mirrors the two in the firmware repository and that the phase context
named only on the firmware side.

The distinction that governs every edit here is fixed and not negotiable per site: **a `#` comment
is deleted; a docstring is repointed; a user-visible string is rewritten.** Docstrings are not
comments, and Click docstrings in particular are the text a user reads in `--help`, so a comment
sweep must not touch them.

Output: an app repository whose runtime output, docstrings and project instructions all name wiki
pages instead of vanishing paths.
</objective>
