<objective>
Sever the one coupling that makes the firmware `doc/` deletion catastrophic rather than merely
noisy, so that plan 168-07 can delete `firestarter/doc/` without silencing the entire app test
suite.

Purpose: `tests/test_dispatch_mirror.py:38` resolves its canonical document through `fw_path`, and
`fw_path` **raises** when the firmware repository is present but the target is not
(`tests/fw_presence.py:130-140`). That call is at module scope, so pytest aborts during collection:
reproduced this session as `Interrupted: 1 error during collection`, `1972 tests collected`,
**zero tests executed**. Every downstream gate in this phase would then report nothing rather than
reporting failure. This is the H-1 ordering constraint and it is encoded here as a wave boundary,
not as a warning: nothing may delete `firestarter/doc/` until this plan has landed.

Output: an app test tree that survives the firmware `doc/` deletion, and a dispatch-mirror gate
whose logic is released from the app repository so plan 168-10 can rebuild it against the wiki.
</objective>
