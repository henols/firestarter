<objective>
Remove the 17 test legs whose oracle is a `firestarter_app/doc/` file, keep the 33 code-side legs
that share those same modules running, and then delete `firestarter_app/doc/` — all ten files,
including the one that is deferred rather than migrated.

Purpose: MIGRATE-02 requires the directory gone and MIGRATE-03 requires the suite to pass
afterwards. The difficulty is that the split runs **inside** five modules totalling 2,678 lines: 21
doc legs and 33 code legs are interleaved, and four of the doc legs already left with plan 168-04.
Cutting too much silently deletes coverage that has nothing to do with documentation; cutting too
little leaves a red suite.

One module the phase context never named is in scope and matters: the packaging module that reads
the **deferred** install guide. That guide is deferred from migration but MIGRATE-02 still deletes
it, so its five legs lose their oracle with nowhere to point. That is a real, named loss.

Output: an app repository with no `doc/`, a green suite, and a written account of what coverage the
deletion cost.
</objective>
