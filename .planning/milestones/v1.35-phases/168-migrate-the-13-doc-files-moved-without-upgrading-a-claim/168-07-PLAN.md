<objective>
Delete `firestarter/doc/` and repair every reference in the firmware repository that pointed into
it — including two lockstep-maintenance rules that are far more than link hygiene.

Purpose: MIGRATE-02 requires the directory gone and criterion 2 requires that no file in the
repository links to a path beneath it. The trap in this plan is `CLAUDE.md`, and D-16 names it: among its
five references are **two separate rules** requiring lockstep maintenance between firmware headers and
sections of the shield-revision document. A find-and-replace pass that treats them as links would
silently retire two real maintenance invariants. That is the single easiest thing in this phase to
lose.

Output: a firmware repository with no `doc/`, no dangling reference, and both invariants intact.
</objective>
