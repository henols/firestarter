METHODOLOGY NOTE — a real instance of the sibling-editable-install trap, caught before it produced
a false result: running the identical `import firestarter; print(firestarter.__file__)` command
with cwd=/workspaces (the meta repo root, which also contains a directory literally named
`firestarter` — the unrelated C++ firmware sub-repo) printed `None` and resolved
`firestarter.__path__` to `['/workspaces/firestarter']` (the firmware repo, not the installed
Python package). Reason: `python3 -c` puts `''` (cwd) on `sys.path`, and Python's implicit PEP 420
namespace-package resolution finds `/workspaces/firestarter` (a directory with no `__init__.py`,
still a legal namespace package) via the ordinary `PathFinder` *before* the editable install's own
appended `_EditableFinder` ever runs. Every command in this evidence file was therefore run with
cwd=firestarter_app (never cwd=/workspaces), which resolves correctly, as shown above.
