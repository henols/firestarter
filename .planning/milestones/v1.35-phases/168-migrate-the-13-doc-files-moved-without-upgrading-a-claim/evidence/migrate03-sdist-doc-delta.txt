=============================================================================

THE PREMISE IS FALSE. No `doc/` file has ever shipped inside the published `firestarter`
package. Deleting `firestarter_app/doc/` in this phase changes the sdist by nothing:
before = 0 doc/ entries, after = 0 doc/ entries.

--- The source of the false premise ---

Everyone citing "3 files ship inside the package" was reading
`firestarter_app/firestarter.egg-info/SOURCES.txt`, a STALE, GITIGNORED build artifact left over
in the working tree from a historic local build environment — not a description of what
`pyproject.toml` or `MANIFEST.in` actually declare. 168-RESEARCH.md recorded its exact contents
before this phase started (2026-08-30): `SOURCES.txt:28-30` listed 3 `doc/*.md` paths, and the
file as a whole (205 lines) additionally listed 39 other entries a clean build never produces —
`.gitignore`, `CLAUDE.md`, `.github/workflows/*`, `.planning/codebase/*.md`, `datasheets/*.pdf`,
`tools/*.py`, `tests/*` — none of which any clean `python -m build`/`uv build` invocation emits
(confirmed again in this session: the freshly rebuilt egg-info directory after this session's
builds carries 0 references to `doc/`, because it was regenerated from the real, current
manifest rules, not from whatever historic local environment produced the 205-line stale copy).

`MANIFEST.in` does not mention `doc/` at all, and `pyproject.toml` declares
`packages = ["firestarter"]` with `package-data` limited to the three JSON files under
`firestarter/data/`. There was never a packaging rule that would have included `doc/`.

--- Conclusion ---

BEFORE: 0 doc/ entries. AFTER: 0 doc/ entries. Delta: 0.

Stating that "three files left the package" would be a false claim inside the milestone whose
entire purpose is preventing exactly that failure mode. The correct, measured statement is: the
packaging change caused by this phase's `doc/` deletions is a genuine no-op, and the belief that
it was not one traced to a stale, gitignored, unregenerated build artifact that nobody had reason
to distrust until it was actually measured against a clean build.
