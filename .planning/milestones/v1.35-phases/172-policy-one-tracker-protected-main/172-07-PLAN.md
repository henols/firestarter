<objective>
Carry the `.github/` files to the three `main` branches by pull request — three small pull requests,
each containing only that repository's `.github/` paths, opened after the rulesets are active.

Purpose: GitHub reads issue templates, community-health files and workflow registrations from the
**default branch only**, and `main` is 733 commits behind `beta` in prom, 531 in `firestarter` and
781 in `firestarter_app`. Files landing only on the milestone branch would not be offered on the New
Issue page within this milestone, and `wiki-check.yml` would stay unregistered and inert. D-08 makes
POLICY-02 observable rather than merely constructed, and the merges double as the first live
exercise of PR-only `main` — which is what Phase 173's POLICY-05 has to document.

Output: three pushed branches, three open pull requests, three evidence files. **No merge.** Plan
172-08 owns the merges.

**The head branch is the whole trap.** A pull request whose head is the milestone branch would drag
the entire unreleased milestone into a default branch. Every branch here is cut fresh from that
repository's `origin/main` in a throwaway worktree, and only the wanted paths are taken onto it —
which also means no `git switch` ever happens in the three working checkouts, so no gitlink moves
and the phase's own artifacts never leave the tree.

`autonomous: false`: Task 2 is a human-action gate before three public pull requests are opened.
</objective>
