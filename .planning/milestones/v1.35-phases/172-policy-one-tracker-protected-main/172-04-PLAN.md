<objective>
Give each repository the native contribution affordance GitHub only reads locally, and remove the
duplication POLICY-01 forbids: three `.github/CONTRIBUTING.md` pointer files, and three README
sections trimmed from a restatement to a link.

Purpose: GitHub reads `CONTRIBUTING.md` only from the repository where a pull request is opened, so
a wiki page alone fires nothing in the two repositories where pull requests actually land (D-02).
Meanwhile the tracker fact is currently stated three times in three different framings across the
three READMEs, which is precisely what POLICY-01 says not to do (D-03). One link replaces each
restatement.

Output: three new pointer files, three trimmed README sections, one evidence file.

**Dependency.** Plan 172-01 must have published the `Contributing` wiki page — every link written
here points at it, and a link to a page that does not exist is the class of claim this milestone
removes. Plan 172-02 must have created the bug-report form, because the four "Include:" bullets
this plan deletes from `firestarter/README.md` are only safe to delete once they exist as required
fields there.
</objective>

## Shared text for all three tasks

Every task in this plan writes the same pointer file. It is reproduced once here so the three tasks
cannot drift; Task 3 asserts all three share one sha256.

The pointer file is short: an H1 reading `Contributing`, one sentence saying the project's
contribution policy lives on the wiki and carrying the single link
`https://github.com/henols/firestarter_prom/wiki/Contributing`, and one sentence naming what that
page covers — where to report a problem, where to open a pull request, and how a change spanning
repositories is coordinated. Nothing else. No restatement of the routing rules, no tracker URL, no
code of conduct, no review-time or support promise, no comment. The three files are byte-identical
so that "stated once" is a mechanical fact rather than an editorial claim.

The README replacement sentence is also the same in all three: one sentence carrying exactly one
link, that same wiki URL, saying that is where to find how to report a problem and where to open a
pull request.
