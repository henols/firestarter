  <action>
Add the `links` capability to `tools/wiki/wiki.py`.

New module constants, following `codegen.py`'s `VALID_*` allowlist idiom:
- `ILLEGAL_NAME_CHARS = '\\/:*?"<>|'`
- `LEGAL_LINK_RE` — a compiled regex matching the one legal internal link form: `[` text `](`
  a target consisting only of characters legal in a page stem, optionally followed by `#` and an
  anchor, `)`. The regex must not match a target containing `/`, `.`, `:` or whitespace.
- `EXTERNAL_LINK_PREFIXES = ("http://", "https://", "mailto:", "#")` — targets matching these are
  ignored; liveness checking is explicitly out of scope and deferred to Phase 172's grep.

New functions:
- `strip_code_spans(text: str) -> str` — removes fenced blocks delimited by three backticks
  (including the fence lines) and inline spans delimited by single backticks, replacing each with
  an equal number of newlines so reported line numbers stay accurate. Getting this wrong produces
  false failures, and a check that goes red for reasons unrelated to the change gets ignored — this
  repository has already demonstrated that failure mode with `catalog-sync-check.yml`.
- `extract_internal_links(page: Path) -> list[tuple[int, str, str]]` — returns
  `(line_number, link_text, target)` for every markdown link in the code-stripped page whose target
  is not external. Detect the disallowed forms in the same pass so they can be reported rather than
  silently skipped: any `](...)` occurrence that is not external and does not match `LEGAL_LINK_RE`,
  any `[[` occurrence, and any `][` reference-style occurrence.
- `check_page_names(source_dir: Path) -> list[str]` — returns a list of failure messages. Reject any
  entry in `source_dir` that is a directory (D-02: flat); any file whose suffix is not `.md`; any
  stem containing a character from `ILLEGAL_NAME_CHARS`, a path separator, or `..`; any absolute
  path. Each message names the offending value and the allowed set with `sorted()`, following
  `codegen.py`'s message shape.
- `check_link_forms(source_dir: Path) -> list[str]` — returns failure messages for disallowed link
  forms and for unresolved targets. Resolution is case-sensitive against the exact set of page
  stems; a target whose lowercase form matches an existing stem but whose exact form does not gets a
  message that says so explicitly, because GitHub will never report it.
- `check_orphans(source_dir: Path) -> list[str]` — the evidence set is the links found in
  `Home.md` and nothing else. `_Sidebar.md` and `_Footer.md` are excluded from the evidence set and
  are also excluded from the set of pages that need to be reached. `Home.md` itself needs no inbound
  link. Every other page must be a resolved target of a link in `Home.md`, or it is reported as an
  orphan. Do not add a flag, an environment variable or a config key that would let a caller count
  sidebar links as evidence — the exemption is what reopens the tautology.
- `cmd_links(args) -> int` — call all three checkers, concatenate their messages, print every
  message to stderr with the `ERROR:` prefix, and return 1 if any exist. On success print one
  `<stem> -> "<title>"` line per page to stdout using `render_title`, then
  `OK: <n> pages, all reachable from Home.md, all internal links resolve, all filenames legal.` and
  return 0.

Register `links` in `_build_argparser()` as a subcommand and add `"links": cmd_links` to `COMMANDS`.
The subcommand's `description=` states the single legal internal link form and lists the rejected
forms, since that is the convention contributors need and comments may not carry it.

Do not add any HTTP client, any network call, or any third-party import.
