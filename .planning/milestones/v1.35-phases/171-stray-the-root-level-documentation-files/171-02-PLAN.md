## Precedence note for the executor

`171-RESEARCH.md`'s corrections table (line 9) outranks `171-CONTEXT.md` wherever they disagree.
Four of its corrections bind this plan:

- **C-2.** An sdist built in `/workspaces/firestarter_app` is a **false positive**. It emits a
  220-entry sdist that *contains* `autocomplete.md` and `things.md`, because setuptools'
  `manifest_maker` re-absorbs the gitignored `firestarter.egg-info/SOURCES.txt` when no
  revision-control file-finder plugin is installed. A build from a pristine `git archive` tree emits
  **173** entries with none of the three, byte-identical before and after this plan's deletions. The
  packaging oracle must be the clean-tree route in Task 3. Warning sign of the wrong route: an entry
  count of 220, or `.gitignore` / `CLAUDE.md` / `requirements.txt` appearing at the archive root.
- **C-4.** CONTEXT.md's claim that a repo-wide grep for `SECURITY.md` returns only the file's own
  title line is **false**. There is a second hit at
  `firestarter/test/native/avr/test_eeprom28c_sdp/RED-BASELINE.md:637` — a Phase 117 record listing
  files that were *untracked at that time*. It is not a link. Disposition: **no action**; it is
  historical-by-intent and editing it would destroy evidence. Do not re-assert CONTEXT.md's claim,
  and do not let the sweep fail on this hit.
- **C-5.** The `SECURITY.md` misrepresentation is **latent, not live**. The file is absent from
  `origin/main` — the app's default branch — and present only on `origin/beta` and the milestone
  branch, so `gh api repos/henols/firestarter_app/community/profile -q .files.security_policy`
  returns `null` **both before and after** this work. It would pass a plan that did nothing. It is a
  vacuous leg and must not appear in any verify block. The branch-tip `git cat-file -e` check (V-04)
  is the real oracle. The Security-tab observation is deferred to the milestone merge.
- **C-7.** `things.md` is **7 lines / 265 bytes with no trailing newline**. `wc -l` reports 6 because
  it counts newline characters. CONTEXT.md's "5 lines" and the ROADMAP's "six lines" are both wrong.
  Any prose written about it must say seven, or avoid the count.
