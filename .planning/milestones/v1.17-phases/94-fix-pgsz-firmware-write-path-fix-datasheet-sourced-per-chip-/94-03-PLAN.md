<objective>
Deliver the FIX-01b boot-block-locked diagnostics (HOST heuristic as the primary, robust,
zero-firmware-risk deliverable) and lock in FIX-02 (the v1.16 golden traces + dispatch-mirror
guard stay green after the Plan 01/02 changes). Optionally add the firmware §6.6 ID-mode
DETECT read as a SEPARATE, clearly-optional task gated on Leonardo flash budget.

Purpose: A write into the seated W29C040's permanently-locked first-16K boot block currently dies
with a cryptic `Timeout verifying ... at 0x0000ff` that LOOKS like a firmware bug. Phase 93 RCA
proved the lock is irreversible silicon (§6.6 has ENABLE + DETECT but NO unlock command); no
firmware change can program page 0. The fix surfaces a clear, honest diagnostic so the operator /
Phase 95 understand the chip is the blocker, not the code — and documents the limitation as
hardware-blocked, never faked.

Output: a host post-failure heuristic hint (primary), the FIX-02 golden-trace regression
confirmation, and an OPTIONAL firmware DETECT task (only if flash budget allows). Page-0
non-programmability is documented as a Phase-93 hardware block.
</objective>
