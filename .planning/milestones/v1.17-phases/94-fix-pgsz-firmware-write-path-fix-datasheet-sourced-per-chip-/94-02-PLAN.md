<objective>
Generalize CR-01: replace the firmware capacity heuristic flash4_page_size(mem_size) with a
datasheet-sourced per-chip page_size carried over the wire (mirroring the read-strobe-us field),
authored only for datasheet-confirmed chips, with the heuristic preserved as the safe fallback.

Purpose: The current heuristic (≤65536→64, ≤262144→128, else→256) is a capacity proxy, not a
datasheet fact — it under-sizes families like AT29C020 (native 256B, heuristic gives 128B).
PGSZ makes page sizing per-chip and datasheet-true while keeping the heuristic as the absent-field
default so unconfirmed chips degrade safely.

Output: the JSON_KEY_PAGE_SIZE wire field (host constant + emit-when-present + firmware PROGMEM key
+ parser + struct field), datasheet-cited page_size authoring in build_db.py for W29C040=256 /
W29C020=128 only (no [ASSUMED] values graduated), firmware safe-fallback consumption, a regenerated
DB, and native + host tests proving consumption and the gates. Dual-repo lockstep.
</objective>
