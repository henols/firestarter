=== ROOT CAUSE ===
W29C040 §6.6 Boot Block Programming Lockout:
The seated chip has the FIRST 16K (0x0000-0x3FFF) boot block programming lockout
feature permanently activated (silicon-level hardware protection, not reversible
by normal write procedures). Writes to this region silently fail — the internal
write cycle never starts (DQ7 poll reads 0x00, the complement of "never committed").

The LAST 16K (0x7C000-0x7FFFF) boot block is NOT locked on this chip.

This is H5 (silicon defect / instance-specific) — NOT H1 (timing), H2 (addressing),
H3 (SDP), or H4 (poll site).
