<objective>
Make the firmware dispatch **only** on `handle->protocol`. Delete the `mem_type` fallback
dispatch chain in `configure_memory()` (former steps 7–11), collapse the `protocol != 0` guard
into a single unconditional terminal `configure_not_implemented(handle); return;` (D-04), remove
`handle->mem_type` from `firestarter_handle_t`, stop parsing the `type` JSON field (all four
`json_parser.c` touchpoints), and retire `MSG_ERR_MEM_TYPE_UNSUPPORTED (0xAE)` plus the
`TYPE_EPROM`/`TYPE_SRAM`/`TYPE_FLASH_TYPE_3`/`TYPE_FLASH_TYPE_4` constants — all in the same commit
as the dispatch deletion (SC#3). Delete the two fallback-specific native test cases (D-05) and add
one minimal `protocol == 0 → fail-closed` assertion (D-06) so SC#1 stays provable.

Purpose: Remove the last vestige that violates the algorithm-first dispatch contract — the
`mem_type`/`type` backward-compat fallback axis. Pure removal; no behavior change for any real DB
chip (all 746 carry a non-zero `algorithm`). Strengthens the fail-closed 12V-VPP hazard invariant.
Output: Firmware that trusts only the real protocol; `type` is unknown-field-skipped on the wire.
</objective>
