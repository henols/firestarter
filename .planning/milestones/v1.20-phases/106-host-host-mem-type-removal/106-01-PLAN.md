<objective>
Remove the numeric `mem_type`/`type` axis from `firestarter/database.py` (HOST-02) and, as a direct consequence, from the wire command payload (HOST-01), then invert the wire-shape and required-keys tests to positively prove `type` is gone from the wire (D-05).

Purpose: Complete the emit side of WIRE-01 — the breaking wire-contract change already landed firmware-first in Phase 105 (fw no longer parses `type`; `json_parser.c` silently skips unknown fields, so the brief window where the host still emitted `type` was harmless). After this plan `algorithm` (carried as `protocol-id` → `algorithm`) is the sole dispatch datum on the wire.

Output: `database.py` with `_ALGO_MEM_TYPE`, the `determined_type` derivation, and both `"type"` dict keys deleted; 7 wire-validation test functions and one required-keys test inverted to assert `type` is ABSENT.

This is a pure DELETION plan — no behavior change for any real DB chip (all carry a non-zero `algorithm`).
</objective>
