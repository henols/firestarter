<objective>
Exercise the write-read-verify oracle end to end on a real chip, once, before twenty positions
depend on it: write this position's own address-attributable image, take three independent
reads with the v1.33 arm's own read command, and judge them by SHA over the full 65536-byte
device size with a script the arm does not own.

Purpose: the app's own consistency verdict compares the reads to each other and never to the
written image. A chip that reliably returns the wrong bytes passes it, and that is exactly the
false green this milestone is exposed to — on the arm whose entire premise is that nothing
changed. This plan proves the independent judge works on silicon and records what it costs.

Output: `bench/cells/BRINGUP-wrv/` completed with the written image, the write record, the
three reads, the judged verdict; and the bring-up row appended to the canonical record.
</objective>
