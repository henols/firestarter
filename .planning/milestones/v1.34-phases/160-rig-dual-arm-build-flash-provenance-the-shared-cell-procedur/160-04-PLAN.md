avrdude's urclock programmer patches the reset vector and one designated interrupt vector

correctly-flashed board. The probe output is what plan 09 turns into a judged-span policy.
This mode must be able to run and record even when a probe returns an error, because "the
bootloader does not support this option" is itself the answer — record the error text rather
than aborting the whole mode.

expected mcu for the target produces a non-zero exit naming both values; and a resolved

behaves as specified.
