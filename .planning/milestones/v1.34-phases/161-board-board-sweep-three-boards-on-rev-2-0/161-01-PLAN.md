## Planner decision PD-1 — the per-position layout, and why RESEARCH's proposal was rejected

`161-RESEARCH.md` proposes `cells/<slug>/positions/<position_id>/written.bin`.
`161-PATTERNS.md` measured that path with `git check-ignore -v` and it is **NOT ignored** —
`bench/.gitignore` is exactly two patterns, `cells/*/reads/` and `cells/*/written.bin`. That
layout would silently commit up to 12 large binaries (~6.5 MB of `run_*.bin` plus 12 written
images). **The measured observation wins.** The layout this phase uses:

| Artifact | Path | Committed? |
|---|---|---|
| position image | `cells/<slug>/reads/<position_id>/written.bin` | no — `cells/*/reads/` |
| position read set | `cells/<slug>/reads/<position_id>/run_NN.bin` | no — `cells/*/reads/` |
| position verdict | `cells/<slug>/WRV-VERDICT_<position_id>.json` | **yes** |
| position provenance | `cells/<slug>/provenance_<position_id>.json` | **yes** |
| per-arm readback set | `cells/<slug>/readback_<arm>/` (6 files) | **yes** |

Consequences, all deliberate: **no `bench/.gitignore` edit is required**; `judge_wrv.py`'s
`run_*.bin` glob does not match `written.bin`, so co-locating them is safe; and the
commit-on-failure exception becomes one command,
`git add -f .planning/v1.34/bench/cells/<slug>/reads/<position_id>/`.
