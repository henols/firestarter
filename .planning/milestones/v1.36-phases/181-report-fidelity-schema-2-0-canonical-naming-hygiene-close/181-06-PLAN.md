<objective>
Make the two numbers a `dev test` operator reads about time mean what they say.

`duration_s` stops being a sum across cycles and becomes the mean over the cycles that ran, so the
field measures a per-operation cost whose meaning does not change with `run_count` — which is
RPT-D1's stated property and the only reading under which a `--fast` value and a default value
measure the same thing (D-05). A real wall-clock `elapsed` is added for the whole command, stamped
once between CLI entry and the first serialization (D-06), and it takes the console row the summed
sum-of-sums used to occupy (RPT-D2, D-07) while the filed issue body carries it too.

Purpose: the row being removed already concedes in its own source that it under-reports — it
excludes the connects, the database load, the identity read and plan derivation — and the docstring
line that justified summing `duration_s` names that very row as the reason. The two requirements are
one change: remove the sum, and the justification for summing goes with it.
Output: one changed fold, one stored field, one replaced console row, one issue-body line, a moved
key-list pin and two evidence transcripts.

**No second derived number is introduced.** Exposing the gap between `elapsed` and the sum of the
step durations is an explicitly deferred idea, and RPT-D2 asks for the sum row's removal rather than
its replacement by another computed one.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| host clock to the report | `time.monotonic` is used rather than `time.time`, so a wall-clock adjustment during a run cannot produce a negative or wildly wrong duration. That reason is already written out at the per-step timing site. |
| Click context to the handler | The start time lives in the per-invocation context `meta` mapping rather than in module state, so one invocation cannot read another's base. |

| report object to the filed GitHub issue body | The one outward crossing. `sanitize_dict` scrubs string leaves; a float is untouched by it and discloses nothing about the host. |
