### Rewording a comment your own deletion falsified

`CLAUDE.md` forbids writing comments into anything under `firestarter_app/`. The rule was
broadened on 2026-08-29 to cover *all* comments, so the older `# Phase 37` / `# Phase 131 D-14`
comments still in the tree are **stale precedent, not a licence**.

The trap fires when a plan deletes a symbol and a pre-existing comment names it. The comment is
now false, and rewording it feels like a fix — but a reword is writing comment prose, and it
grows the `tokenize` COMMENT-token census. It happened three times in waves 2–3:

- 181-03 → `pyproject.toml`, a `(HYG-01 / D-17)` justification block (fixed in `3078e0a`)
- 181-04 → `tests/test_dev_test_cmd.py`, +1 over baseline (self-caught, `4e56c30`)
- 181-04 → `tools/check_devtest_orchestrator.py`, 91 → 94 (missed by its own census; fixed in `ddc0c1c`)

**Correct move: delete the false clause and leave the rest of the base text byte-identical.**
A pure deletion cannot exceed the baseline. The rationale belongs in the commit body and
SUMMARY.md, which is where `CLAUDE.md` says to put it.
