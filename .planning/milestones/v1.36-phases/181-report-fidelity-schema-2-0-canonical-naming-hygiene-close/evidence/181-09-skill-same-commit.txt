D-5 residue
-----------
One commit across two git repositories is structurally impossible -- there is no
single commit boundary that spans a meta repo and a submodule with independent
histories. D-5's "same commit" requirement is discharged as far as two repositories
allow: two commits landed inside this one task (Task 1), in the ordering and for
the reason recorded above, each commit message naming the other side's sha. The
record states this plainly rather than claiming a literal same-commit that did not
happen.
