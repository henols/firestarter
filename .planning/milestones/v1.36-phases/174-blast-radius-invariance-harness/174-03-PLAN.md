<objective>
Close the oracle: pin the report schema's key lists, make the shape registry impossible to widen or narrow
silently, and pre-seed the whole re-key ledger with the milestone's known blast radius stated up front.

Purpose: a frozen-hash table can be defeated three ways that the table itself cannot see — delete the
inconvenient row, add a row that widens the oracle, or let an additive schema key slip in unpinned. This
plan closes all three, and it fills in the ledger so that a fifth, undeclared re-key later in the
milestone shows up as an unplanned row rather than blending into the noise.

Output: a committed sorted shape_id list, seven element-wise schema key pins, a four-way closure
sentinel, six pre-seeded ledger rows, the narrated `MILESTONES.md` ledger, and two evidence transcripts.
</objective>
