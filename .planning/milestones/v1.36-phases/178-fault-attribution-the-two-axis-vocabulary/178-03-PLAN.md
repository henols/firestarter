<objective>
Register the `shape_id` Phase 174 reserved for this phase -- `attr01-status-axis-transport-fault` --
so the frozen corpus contains a report that actually exercises the status axis, and so ATTR-04's
Leg A stops being an argument about an empty set.

Phase 174's oracle currently proves that 17 shapes, none of which carries a status, still hash to
their pinned literals. That is a real gate but a narrow one. After this plan the corpus contains an
18th shape whose steps carry `status: ERROR`, its `to_dict()` snapshot pins the exported key name,
and every one of the 17 inherited hashes is still measured unmoved -- which is what "the status axis
is excluded from the hash" means at corpus scale.

Purpose: the moment this shape's hash and snapshot are committed, the field name `status`, its
values, and the result-axis value a transport fault carries all become published identity. Undoing
any of them afterwards needs a declared re-key row in `rekey_ledger.py`, a matching `MILESTONES.md`
row, and a green cross-tree checker in a second repository. That is why this plan opens with a
decision task.

Output: an 18-shape corpus, a measured hash nobody transcribed, and a recorded seal showing the
inherited 17 did not move.
</objective>
