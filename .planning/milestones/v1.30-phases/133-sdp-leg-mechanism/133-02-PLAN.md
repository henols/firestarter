Widen `_run_step`'s exception handling to the exact set D-08 names, in the exact order D-08 requires,
and prove with the frozen before-image from plan 133-01 that only the three intended rows of behaviour
changed.

that reads as a broken chip. This project already has a documented false-green trap in exactly the
no-board shape. D-08 resolves that by re-raising the two run-fatal subclasses first.

Output: two new `except` clauses in `_run_step` in a proven-correct order; a corrected docstring; the
precedence matrix advanced by exactly three named rows; LEG-11's four behavioural proofs.
</objective>
