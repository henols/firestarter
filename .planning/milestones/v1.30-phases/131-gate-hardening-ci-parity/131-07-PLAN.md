## Note on the self-excluding scan pattern

The `automated` block in task 2 writes the six forbidden command forms with a bracketed final
character — `gh workflo[w] run`, `git pus[h]`, and so on. `[w]` matches `w`, so the regex still finds
every real occurrence in the scanned files, while the **regex text itself** contains none of the six
literal phrases. Without this, the scan command would match itself and the gate could never pass on
an honest tree. This is the same self-reference problem v1.23's claim gate hit at `ROADMAP.md:2468`,
solved there with an exemption; here a bracket is cheaper and needs no allow-list. Do not "simplify"
the brackets away.
