<objective>
Close LEG-17 with a test per laundering route, and LEG-13 with the pinning test that proves the N-of-M
ratio drops when the oracle does not run.

command whose *absence* is itself a finding, and the exit-code table has no vocabulary for that.

requirements.
</objective>
