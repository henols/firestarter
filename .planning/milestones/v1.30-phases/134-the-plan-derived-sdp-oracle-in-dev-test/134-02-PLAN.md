<objective>
Build the oracle: a new single-run dispatcher in `firestarter_app/firestarter/chip_test.py` that writes
a pattern, reads it back, and decides the verdict from **read-back equality** behind a no-default truth
table — plus the `_dispatch_step` arm that routes to it, and the tests that prove each arm.

Purpose: this is the phase's reason to exist. Every other plan renders, gates, or counts what this one
decides. Get the truth table wrong and the milestone ships a leg that reports success because a write
returned without error.
Output: `_dispatch_sdp_leg`, arm 6, and the LEG-05/06(engine)/07/08/16 proofs.
</objective>
