<objective>
Consolidate the two divergent host protocol-name vocabularies (`ic_layout.proto_display`
and `protocol_info_data`) onto a single canonical `{protocol_id: display_name}` source
so `firestarter info` / `list` / `search` render one consistent, ASCII-normalized
canonical name per protocol. Display-only: CLI grammar, dispatch keys, and every
`chip_database.json` value stay untouched.

Purpose: Kill the recurring IN-01 info-vs-list re-divergence class by structurally
forcing both render paths through one dict (HOST-01 "consolidate"). Apply the
Phase-100 operator-approved canonical names to the host.
Output: A new `_PROTOCOL_DISPLAY_NAME` map, both maps rewired to it, the D-04 coverage
reconcile (add 0x34, drop 0x11), the two anti-regression tests, the one regenerated
snapshot, and re-verified GATE-01/02/03.
</objective>
