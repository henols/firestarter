## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `workflow_dispatch` input -> workflow expression / shell | An operator-supplied value reaches `draft:`, `tag_name:` and a `run:` body's environment |
| release job (`contents: write`) -> repository | The job can push commits and create tags and releases; this plan adds no permission |
| composite action -> calling job | The action inherits this job's write permission and workspace |

Matches the shipped `BETA_VERSION` pattern. |
| T-128-08 | Repudiation | a hollow report keyed on `conclusion`, so a release silently ships without the py32 asset and the run page says nothing | medium | mitigate | the condition reads `steps.arm.outcome`; the file is asserted to contain zero occurrences of `steps.arm.conclusion`; firing is OBSERVED in rehearsal run B, not assumed |
