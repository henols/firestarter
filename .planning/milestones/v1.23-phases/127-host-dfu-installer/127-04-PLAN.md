<objective>
Close the live `--usb-id`-accepted-on-stable gap with one shared refusal helper, and prove channel
gating both ways in one test module using one subprocess per simulated version.

Purpose: `hidden=not _PY32_ENABLED` hides an option from `--help` but does not reject it — measured
live, `--usb-id 1a86:8012 --list` exits **0** on a simulated stable build while `--dfu-probe` exits 2.
That is a gated feature leaking onto stable. And because `_BOARD_CHOICES` is computed at import time, a
test that monkeypatches the version in-process would prove the wrong thing.

Output: `_reject_py32_only_option()` with both call sites, and `tests/test_py32_channel_gating.py`
covering HOST-02 and HOST-08 in both directions, deterministic in both CI legs.
</objective>
