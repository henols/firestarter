<objective>
Read written flash back over `DFU_UPLOAD` and compare it byte-for-byte with the payload, recording the
outcome as an enum on the flasher — soft-failing when verification is impossible, hard-failing when it is
possible and the bytes differ.

Purpose: py32 is currently the project's only install path that writes without verifying. avrdude
verifies by default and fails on mismatch on all three AVR boards; HOST-03 restores that parity for the
DFU path. And the two cases where verification genuinely cannot be grounded — a device that says it
cannot upload, and a dialect where the host does not choose the load address — must be recorded as
*could not verify* rather than reported as success.

Output: `VerifyResult` and the readback wired between the download and the hoisted `_finish()`; a
completion line that says **written but NOT verified** when it was not; and the mock-only ceiling written
where a reader meets it.
</objective>
