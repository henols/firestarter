<objective>
Tighten the host flash-envelope guard from the physical part size to the application region Phase 126
actually reserved, and hold the host constants honest with a fail-closed cross-repo gate that parses the
firmware repo's linker script.

Purpose: `_check_envelope` bounds on `FLASH_BASE + FLASH_SIZE` = 128 KiB while the linker script reserves
only 120 KiB for the application and gives the top 8 KiB to `CONFIG` (Sector 15). A rogue 128 KiB image
would be accepted by a guard that is looser than the map it claims to enforce. And a host constant that
mirrors a firmware file without a gate is a constant that silently rots the moment Phase 129 moves the
map.

Output: `APP_REGION_SIZE` / `APP_REGION_END` / `CONFIG_REGION_SIZE` with `_check_envelope` bounded on the
application region, and `tests/test_py32_flash_map_host.py` carrying the envelope behaviour tests and a
non-vacuous, fail-closed linker-script parity gate.
</objective>
