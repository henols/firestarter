<objective>
Hoist `_finish()` out of both download strategies into `flash()`, and extend the existing fake USB device
with an UPLOAD arm and a real-pyusb-shaped `ctrl_transfer` signature — all with zero behaviour change,
so Plan 127-09 has one correct place to insert the readback.

Purpose: D-12 requires the readback to happen **before** `_finish()` leaves DFU mode and lets the device
reset off the bus. But `flash()` never calls `_finish()`; each downloader does, as its last statement.
Inserting the readback where D-12's wording says would put it after the device has already gone. Hoisting
makes the ordering structural instead of a convention a future edit can break.

Output: exactly one `_finish()` call site, in `flash()`; an extended `_FakeUsbDevice`; and A5 converted
from an inferred claim to a measured one.
</objective>
