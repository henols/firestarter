<objective>
Obtain this phase's own ARM evidence — a successful CMake configure **and** build of the tree
carrying `src/rurp_vpp.cpp` in the ARM source manifest — as a CI workflow run URL plus a head SHA,
behind a structural operator gate.

Purpose: D-12 names the seam in `FIRESTARTER_COMMON_SOURCES`, which means the ARM target now compiles
it. `arm-none-eabi-gcc`, `cmake` and `ninja` are all absent from this devcontainer, and the milestone's
Validation Ceiling forbids citing a local build as ARM evidence — it would be impossible here anyway.
D-13 obtains the evidence in *this* phase rather than riding Phase 126's, on the same attributability
grounds the 125 → 126 ordering exists for: if the seam breaks the ARM build, this is the phase that
learns it. D-14 makes the push and dispatch an outward-facing action requiring an explicit operator
gate that no autonomous flag can bypass.

The gate here is **structural, not a flag**: no task in this plan executes `git push` or
`gh workflow run`. The plan re-proves the safety argument, prints the exact commands with every value
filled in, and stops. The operator runs them. Only then does the plan resume, with read-only queries.

Output: a recorded run URL, database id, head SHA, event and conclusion, with the configure and build
step outcomes recorded separately; or a recorded rejection or failure with its exact message.
</objective>
