<objective>
Create `firestarter_app/tests/fw_presence.py` — the one place the host suite decides whether the firmware
sibling is present — plus the committed deliberately-incomplete fake sibling tree and the subprocess tests
that prove a present-repo-with-a-missing-target is a hard failure rather than a skip.

Purpose: A-7 measured the current proxy failing OPEN. Seven modules each derive "firmware absent" from
`not <some file>.exists()`, so a firmware **rename** flips gate legs PASS→SKIP at exit 0 with a false
"firmware absent" reason — and moving firmware files is this milestone's entire premise. BASE-02 splits
that proxy: repo presence keys on `../firestarter/.git`; a missing scan target under a present repo is a
hard failure.

Output: one helper module, one committed fixture tree, one test module.

**This plan does not touch the seven proxy-carrying modules.** That rekey is D-09's one-pass job and it is
plan 123-08; this plan builds and proves the single helper that pass substitutes in, so the rekey is a
mechanical substitution against something already tested rather than seven parallel rewrites. The
committed fake sibling reached through an env seam is D-12, using RESEARCH's Mechanism 1 rather than
CONTEXT D-12's suggested `.git` gitfile, which was measured not to work.
