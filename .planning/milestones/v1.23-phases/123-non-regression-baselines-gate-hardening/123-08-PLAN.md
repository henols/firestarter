inventory with the one test that resolves all of it.

scratch.

full. D-09's second half, the recurrence lint that stops the idiom returning, is plan 123-09.

label; do not read it as CONTEXT's D-13.

suite so far has counted decorators, and that is precisely how the inline guard survived.
