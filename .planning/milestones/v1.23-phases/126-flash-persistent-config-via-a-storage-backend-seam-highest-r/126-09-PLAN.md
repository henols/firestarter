<objective>
Exercise the shipped dual-slot core against a RAM fake through six distinctly named tests plus an
independent CRC known-answer anchor, with the interrupted-write case modelling the real primitive's
64 discrete word stores and the CRC-rejection case carrying an explicit `length`-bound ordering
assertion.

Purpose: ROADMAP Criterion 4 names six behaviours and forbids an aggregate pass/fail. D-02 requires
those six to run against the code the ARM target ships rather than a copy, which is why the harness
compiles `platform/py32f071/src/config_storage_dualslot.cpp` by path. D-05 adds the seventh function
because six tests that all route through one unverified CRC would agree with each other and with
nothing else. And the phase's highest-severity threat — a `length` field read from flash and used as a
copy bound on an MPU-less Cortex-M0+ — is asserted here as an ordering, not as an outcome.

Output: `firestarter/tests/test_config_storage_dualslot.py`, green, with every one of its assertions
demonstrated able to fail against a mutated copy of the core.
</objective>
