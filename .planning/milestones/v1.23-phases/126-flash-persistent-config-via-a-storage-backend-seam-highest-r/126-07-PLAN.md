<objective>
Author the HAL-free dual-slot storage core: the vendored `StoredConfiguration` record, the
`CONFIG_MAGIC` constant, a table-free reflected CRC-32, and the scan/validate/select/alternate
algorithm over three injected flash primitives — in one translation unit that the ARM backend and the
host test both compile from the same source.

Purpose: D-02 is the most consequential decision in this phase. This project has twice spent a whole
phase unwinding a gate that tested a copy or supplied its own answer, so the algorithm is written once,
with its flash access injected, and the host suite compiles the shipped file by path. D-03 places it
under `platform/py32f071/src/` so it costs the AVR targets nothing. C-2 replaces D-16's unimplementable
trailing-word commit with a whole-page program whose completion is the commit, and V5 makes the
validation order — `magic`, bounds-checked `length`, `crc32` — load-bearing rather than incidental.

Output: `platform/py32f071/src/config_storage_dualslot.h` and `.cpp`, named in
`PY32_PLATFORM_SOURCES`, proven to compile and run under host `g++` with zero warnings.
</objective>
