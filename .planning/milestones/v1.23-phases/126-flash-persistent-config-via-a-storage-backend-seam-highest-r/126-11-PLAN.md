Obtain the phase's ARM evidence — a CI workflow run URL plus head SHA showing Configure and Build each
independently successful — behind a structural operator gate in which no task runs the push or the
dispatch, and re-derive every claimed fact read-only before accepting it.

RESEARCH rated Medium-low confidence and untested. This plan is where both are observed.

observations; the pushed ref's manifest and linker content verified against the local tree; and either
a green record or a failure recorded with its log excerpt and the named fallback.
