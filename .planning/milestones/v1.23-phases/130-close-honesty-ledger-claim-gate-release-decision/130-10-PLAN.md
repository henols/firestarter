false premise — the two deliberate in-scope additions to CLOSE-01's stated four-file list.

intent, record the correction, leave `REQUIREMENTS.md` alone*, and it was built for **mechanisms turning

**mechanism**, and the exception must be drawn explicitly so it does not read as discipline erosion.

misled there, while **FUT-N04 states the falsehood bare as the first of four deferral reasons on a live
forward-looking item**.

and is owned by plan 130-06 — so no requirement is widened by it, but D-06's "two VTOR clauses" framing
must not be read as the complete site list.
