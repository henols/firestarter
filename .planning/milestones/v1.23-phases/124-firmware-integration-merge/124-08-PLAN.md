<objective>
Make the provisional pin map unable to energise a PROM, at a site a native test can actually reach.

Purpose: MERGE-04's wording — *"a native test proves..."* — is what makes the placement decision. D-11
puts the refusal in the shared operation layer for that reason, but correction **C-4** shows the natural
site inside D-11's reading is unreachable: `[env:native]`'s `build_src_filter` compiles only `src/proms/`,
`src/boards/rurp_serial_utils.cpp`, `src/json_parser.c` and `src/operation_utils.cpp`, so
`src/firestarter.cpp` — home of `is_memory_cmd`'s only production caller — is never linked into the native
test binary. The reachable chokepoint is `configure_memory()` in `src/proms/memory.cpp`, which sits behind
exactly D-12's eight commands with no hand-maintained second list.

This plan also closes the second half of W-3: `check_orphan_provisional.py` goes green here, so its
expiring Phase-123 test is inverted in the same commit.

Output: a platform-neutral provisional flag with real consumers, a refusal at `configure_memory()`, a third
native environment that compiles the production path with the flag set, and a suite that proves all eight
commands refuse.
</objective>
