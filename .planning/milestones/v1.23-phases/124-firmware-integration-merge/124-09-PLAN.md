<objective>
Make the pin-map `#error` guard structurally able to fire. As landed, the board header defines the
configured macro to 1 roughly thirty lines above the `#if !CONFIGURED` that tests it, so the guard cannot
fire under any build configuration — a hollow gate inside the branch being landed, and one of the
milestone's named research findings.

Purpose: D-14 restructures it by hoisting the guard into a dependency-free fragment header and moving the
`#define` out of the header into the CMake defines, so the header only tests what the build supplies. The
fire-proof is a pytest that preprocesses a minimal translation unit with the macro unset and asserts a
non-zero exit plus the error text. RESEARCH executed exactly three discriminating arms with the host
compiler — unset fails, `=1` succeeds, `=0` fails — so this is mechanical rather than argued.

Output: a fragment header, a CMake-supplied definition, and a three-armed fire-proof.
</objective>
