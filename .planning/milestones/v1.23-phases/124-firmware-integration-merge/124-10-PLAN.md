Close work items **W-1 half (b)** and **W-2**: re-baseline the live recorded truth to the post-landing
tree with the build state pinned, and discharge MERGE-05 and MERGE-06 as exit codes on the final tree.

Purpose: after this phase's five code-bearing plans, the tree no longer matches BASE-01, and that is
licensed by MERGE-05. But `scripts/baseline/size_baseline.json` is the DEFAULT both gates read, so leaving
it at BASE-01 means a bare run of either gate is red on a correct tree — the "silently forgotten" shape
the operator's tie-breaker rejects. Phase 125's VPP-03 already expects a *Phase-124 baseline* to measure
against. This plan writes it.

Purpose (second): the recorded native watermark of 360 is a **warm-cache** artifact. RESEARCH measured the
identical unmerged tree at **456** cold, and the merged tree at **1166** cold / **998** warm — an increase
of roughly 638 to 710, driven by `include/rurp_platform_compat.h` now defining program-memory macros that
ArduinoFake's own header redefines, across six more macro names and about 27 more translation units. That
is benign but it is not zero, and the gate cannot tell. The watermark must be re-measured honestly with the
build state stated, never guessed down and never quietly overwritten.

Output: a new recorded baseline, a repaired fixture set, and the two requirement-level exit codes.
</objective>
