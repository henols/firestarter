<objective>
Convert the shared `DEV_TOOLS` switch from presence-semantics to value-semantics, per the operator's
verbatim instruction recorded in D-02: *"the test must work in the same way for all platforms, so it must
be fixed."* All three comment-shaped alternatives were declined.

Purpose: today `DEV_TOOLS=0` would perversely **enable** dev tools, because every conditional tests
presence. The ARM target expresses "dev tools off" by omitting the define — a different mechanism from the
one AVR uses. D-02 makes it one mechanism on all four targets: a single shared default of 0, and every
conditional tests the value. This is MERGE-08's third defect, and per D-03 it lands as its own commit
after the landing because that content is not on the branch being landed.

Output: six converted conditionals, one shared default, and a measured zero AVR cost.
</objective>
