<objective>
Obtain MERGE-02's ARM evidence — a successful CMake configure **and** build — as a CI workflow run URL
plus a commit SHA, and confirm MERGE-03's trigger is live on the pushed branch.

Purpose: `arm-none-eabi-gcc`, `cmake` and `ninja` are absent from this devcontainer. No local command can
produce evidence about the ARM target; the Validation Ceiling forbids citing a local `pio` run as ARM
evidence, and it would be impossible here anyway. D-08 obtains the evidence by pushing the firmware
milestone branch and dispatching the ARM workflow. D-09 makes that push an outward-facing action requiring
an explicit operator gate that `--chain` and `--auto` cannot wave through.

The gate in this plan is **structural, not a flag**: no task here executes `git push` or
`gh workflow run`. The plan prepares, verifies the safety argument, prints the exact commands, and stops.
The operator runs them. Only then does the plan resume, with read-only queries.

Output: a recorded run URL, head SHA, conclusion and event; or a recorded rejection with its exact message.
</objective>
