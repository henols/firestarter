<objective>
Commit what the operator actually sees, so the sentence cannot drift without someone choosing to
change it.

Plan 200-01 proved the path works on one part. This plan turns that into evidence by pinning the
rendered output of the real installed entry point for two parts, one from each of the two classes
RESEARCH.md § G-1 separated: `MBM27C1000`, whose 6000 mV is a `VCC_VOLTAGES` rail-table slot like 281
of the 284, and also the part gh#70 reported so a reporter would recognise it; and `MBM27C4001`,
which is one of the only three rows in the 284 whose `vdd_mv` is a datasheet-cited override. If the
amended verb is ever revisited, the committed evidence for both classes is already there.

The blast radius was measured, not assumed: of 32 existing snapshot entries only two render `info`,
and both of their chips carry `vdd_mv` 5000, so neither gains a row and neither gains a warning. This
phase's snapshot change is therefore purely additive, and the gate is stronger than Phase 199's —
insertions with exactly zero deletions, which is a byte-identity proof for every pre-existing line in
the file.

Purpose: make VCC-01's "says so where the operator will see it" a committed artifact rather than a
claim, and make VCC-02's defined shape inspectable side by side with the `no_pinout_warning` block it
generalises.
Output: two new subprocess characterization tests, four new `.ambr` entries, and a numerically proved
zero-deletion diff.
</objective>
