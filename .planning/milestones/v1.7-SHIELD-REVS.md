**v1.8 substrate seed — Shield-Detection UX & Future-Rev Substrate:** three design directions surfaced post-R41-resolution (2026-05-26 — operator session); none gating on v1.7, parked as v1.8 backlog:

- **Option A — Reinstate INPUT_PULLUP (rejected).** Software-only revert to pre-Plan-01 divider math (internal Rpu as R_top). - **Option B — Future Rev 2.4 external R_top (deferred, additive).** Add a fixed `R_top = 10kΩ` from A3 to +5V on the next shield revision. Gated on Anders-upstream Rev 2.4 spin (outside our control).
- **Option C — Operator-UX `firestarter rev --identify` (deferred, host-only).** Host CLI helper that prompts the operator with per-rev visual differentiators (JP4 two pads in a line vs three pads on a 2x2 grid, R41 color bands / SMD code, silkscreen letters) and writes the EEPROM byte. **Physical limits** (regardless of which option ships): Rev 2.2 vs Rev 2.3 are *electrically isomorphic* at the detect divider (both R41=10kΩ to GND directly, not "via JP4" — corrected 2026-09-10, Phase 182). **Also corrected the same date: JP4's footprint does NOT differ between Rev 2.2 and Rev 2.3 either — both are the 2x2, 3-pole selector; the footprint change is one revision earlier, at Rev 2.1 → Rev 2.2 (see "Rev 2.2 provenance discipline (Phase 182)" at file end). ### JP4 is top-side; JP5 through JP9 are all bottom-side

Read from the Rev 2.2 and Rev 2.1 gerber bundles' per-layer `%TO.C` component attributes:

| | Side | Layer evidence (Rev 2.2 gerbers) | Type |
|---|---|---|---|
| JP4 `P1_VPP_JMP` | **Top** | designator on `F_Silkscreen`; pads on `F_Mask` **and** `B_Mask` (through-hole); `top` in the pos-CSV | pin header — the VPP selector |
| JP5 `A19_CUT` | **Bottom** | `B_Silkscreen` + `B_Mask` only; absent from every front layer | bridged solder jumper |
| JP6, JP8, JP9 "Bodge point" | **Bottom** | `B_Silkscreen` + `B_Mask` only | bridged solder jumpers |
| JP7 "Tin foil socket" | **Bottom** | `B_Silkscreen` + `B_Mask` only | **open** solder jumper |

All six appear in both the Rev 2.1 and Rev 2.2 bundles, so **none of JP5–JP9 is a later addition** —
they are not Rev 2.3 features, and JP4 is not a Rev 2.2 feature. The front silkscreen carries only
`JP4`, which is why a front-layer search for JP5 comes back empty and can be misread as absence.
It is also why the Rev 2.2 evidence photograph shows JP4, JP5, JP6 and JP9 in one frame: that is
the **back** of the board, where JP4's through-hole pads sit alongside the five solder jumpers.

Designator values and jumper types are from the only committed schematic that carries them,
`.planning/milestones/v1.7-artifacts/upstream-rurp/hardware/RelativelyUniversalROMProgrammer.kicad_sch` (`(rev "2.3")`);
their presence on Rev 2.1 and Rev 2.2 is from those revisions' own gerber bundles, per the
read-Rev-2.2's-own-artefacts rule stated above. Consistent with that rule, this section cites no
shared schematic blob for any Rev 2.2 claim.
