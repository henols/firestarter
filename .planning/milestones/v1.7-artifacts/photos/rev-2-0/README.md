# Photo directory: RURP Rev 2.0

Operator landing slot for mandatory board photos (Plan 31-03).

Place the following files here (JPEG, phone camera, native resolution):

- `top.jpg` — full top view, silkscreen-version string visible in frame
- `bottom.jpg` — full bottom view
- `silkscreen.jpg` — macro of silkscreen-version region (SILK-01 evidence; must be readable at 100% crop)

Optional detail shots (improve Phase 32/34 fidelity):
- `socket-detail.jpg` — ZIF/DIP socket area
- `jp4-detail.jpg` — jumper / detect-resistor region

Filenames are case-sensitive. Do not re-encode JPEGs. JPG files are gitignored (substrate only).
