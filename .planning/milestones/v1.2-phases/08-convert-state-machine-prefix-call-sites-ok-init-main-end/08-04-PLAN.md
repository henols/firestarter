Wave 4 — land the firmware emit-side migration for the "simple" OK/INIT/MAIN/END/DATA populate-sites: the unconditional macro families (LOG_OK_ID_* / LOG_INIT_ID_* / LOG_MAIN_ID_* / LOG_END_ID_* / LOG_DATA_ID_*) in `logging_id.h` (Phase 7 Plan 01 pattern continues), plus the call-site conversions that map 1:1 to existing catalog IDs without payload-shape changes — `send_main_done`/`send_init_done`/`send_end_done` in `operation_utils.cpp`; `send_ack_const("Req data")` + `log_data_const("Sending data")` in `eprom_operations.cpp`; the four populate-sites in `proms/eprom.cpp` / `proms/flash_type_3.cpp` / `proms/flash_type_4.cpp` (R-02 INFO sites); the DATA-progress emit in `proms/memory.cpp`.

Out of scope for this plan (deferred to Plan 05 because they need different macro shapes or share the same files):
- `send_ack_const("Ready")` + VPP/VPE voltage split + `fw_get_version` + `hw_get_version` + `hw_get_config` in `hardware_operations.cpp` (P-01/P-02/P-03)
