Wire frame (locked per CONTEXT §D-01..D-04):
  bytes 0..3: 0xAA 0x55 0xAA 0x55              (magic preamble)
  byte 4:     len = 1 + param_count + 1        (id + params + crc; excludes len itself + 0x0A)
  byte 5:     id
  bytes 6..N: params (raw, MSB-first per type)
  byte N+1:   crc8 over [id, params] — poly 0x07, seed 0x00, no refl, no XOR
  byte N+2:   0x0A (re-sync anchor, NOT a delimiter)
