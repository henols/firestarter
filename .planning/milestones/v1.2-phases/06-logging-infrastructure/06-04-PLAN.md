<objective>
Wire the host-side firmware-version refuse guard (LFW-05 + LHOST-04). When the host probes a firmware reporting major version < 3, raise `FirmwareOutdatedError` with an operator-facing message specifying the required version and the install command. Add a developer-only environment-variable escape hatch (`FIRESTARTER_DEV_ALLOW_PRE_V12=1`) so bench scripts keep working through Phases 7-8 while firmware still reports v2.0.11. Resolve the PATTERNS gotcha by adding an explicit `except FirmwareOutdatedError: raise` clause in `check_current_firmware` so the error surfaces to the operator rather than being swallowed by the broad `except SerialError`. Unit-test all four paths.

Purpose: User-facing manifestation of the lockstep upgrade contract (PROJECT.md "Constraints"). The host guard is wired in Phase 6 even though the firmware version bump itself lands in Phase 9 — armed but not yet tripped on a real firmware build until then.

Output: pytest passes 4 new tests covering refuse / accept / escape-hatch / malformed-version paths.
</objective>

| environment variable → policy bypass | Developer-only escape hatch; if leaked to a production user environment, would bypass the lockstep refuse. |
