<!-- Codegen public CLI (target state — this plan establishes it) -->

argparse CLI signature:
  python3 codegen.py --catalog <path/to/messages.toml> \
                     --target <output/path> \
                     --language <cpp|cpp-table|python> \
                     [--check]

Languages:
  cpp        → emits messages.h (header guards, severity defines, MSG_* ID defines, MSG_PARAM_BYTES_TABLE extern, MSG_PARAM_COUNT macro)
  cpp-table  → emits messages.c (PROGMEM 256-byte designated-init table, 0xFF fill for unallocated)
  python     → emits messages.py (SEVERITY_* constants, MSG_* ID constants, MessageDef dataclass, CATALOG dict)

--check only validates the catalog (LCAT-02 / LCI-04 gate); no files written; non-zero exit on violation with a clear error.

TOML schema (the catalog is authoritative — codegen treats it as read-only input):
  [catalog]
  version = 1
  project = "firestarter"

  [[messages]]
  id            = <int 0..255, unique>
  name          = "MSG_<UPPER_SNAKE>"             # unique, matches ^MSG_[A-Z][A-Z0-9_]*$
  severity      = "OK|INIT|MAIN|END|INFO|WARN|ERROR|DATA"
  format        = "<printf format string, non-empty>"
  params        = [{ type = "u8|u16|u24|u32|i8|i16|i32|ascii_str", render = "<optional override>" }, …]
  wire_format   = "id_frame"  # or "text" for the FW handshake exemption (MSG_OK_FW_VERSION 0x03, MSG_OK_FW_HANDSHAKE 0x06)
</interfaces>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| meta-repo → sub-repos | Vendored catalog file is the only mechanism enforcing the meta-repo's authority — drift between vendored copies silently corrupts the protocol contract. |
| catalog file → codegen | Catalog file is human-edited; codegen treats it as authoritative input. |
| codegen output → firmware + host build | Generated files are committed; CI drift gate (Plan 05) is the only barrier against post-hoc tampering. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-06-01 | Tampering | `firestarter/tools/catalog/messages.toml` vs `firestarter_app/tools/catalog/messages.toml` drift | mitigate | `sync_to_subrepos.sh` does `diff -q` post-copy and exits non-zero on mismatch; Plan 05 adds a CI cross-sub-repo byte-identical assertion. |
