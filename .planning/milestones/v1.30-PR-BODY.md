## v1.30 — SDP Surface Retirement & Behavioral Lock Proof

Host-only. No firmware change, no dual-repo lockstep, no `.hex` re-cut.

Replaces `firestarter dev sdp <chip> enable|disable` — a command whose `disable` half duplicated
work `write` already does automatically, and whose `enable` half changed a state that provably
cannot be read back — with a leg in `dev test` that decides on **read-back equality**, never on
whether a write call returned without error.

### What's in this PR

- **`dev sdp` deleted.** `disable`'s behaviour survives as `write`'s default auto-unlock (declinable
  via `--skip-sdp-unlock`). `enable` is **withdrawn with no replacement** — tracked as Backlog 999.28.
- **A six-step SDP leg** derived from `sdp_capability()`: baseline transition write (both directions),
  lock, inhibited write, unlock, restore. An unexpected write *success* after the lock reports **BAD**
  and exits 1 — never SKIPPED.
- **Seven laundering routes** to a silently-not-running oracle are closed and tested, not the six the
  research named — the baseline gate is a seventh, and it is named as such so the set never reads as
  exhaustive.
- **Exit precedence fixed**: `marginal` was outranking `BAD` under `max()`, contradicting both the
  source comment and the docstring. 12 pre-existing exit-2 sites audited.
- **Dev-tools channel gating**: a stable install exposes only `dev read` and `dev test`, gated by
  genuinely *not registering* the other six — not `hidden=True` — with an informative refusal rather
  than Click's generic "No such command".
- **The SDP partition is now derivable in-repo** from `infoic.xml`'s flags bit 15, instead of a
  transcribed 65-token list. **43 ALLOW / 41 REFUSE / 84 unchanged**, verified nine independent ways.
- **`ci` is green** at watermark 35 after roughly two months red.

### What this does NOT claim

**The causal claim "the lock inhibited the write" is not proven.** A locked die is unrepresentable in
either repo's stubs — both model the bus, never the die's protection state. No fixture simulates real
inhibition; the fixtures pin the host's *response* to a scripted read-back. **No AT28C silicon was
tested.** Protocol `0x0D` remains `UNVERIFIED`.

This is stated in the milestone's honesty ledger and enforced by a claim gate that scans the closing
