<objective>
Migrate the firmware host→fw JSON command ingest into the Phase-49/50 COBS framing layer.
Delete the legacy `{`-peek / discard-non-`{` loop outright (D-05) and replace it with a single
call to the existing Phase-50 decoder `rurp_communication_read_data()`, which COBS-decodes
in place, verifies CRC8 BEFORE the JSON parser sees any byte (V5 / ADR §4.4), and drains to the
next `0x00` on any failure (D-06). Remove the blocking `rurp_communication_read_bytes()` read from
`init_programmer()` (the data is now pre-filled by the CMD_IDLE decode step). Add the
`CMD_FRAME_MAX` constant (firmware half of the host/firmware parity pair).

Purpose: closes FRAME-05 on the firmware side and the CRC-01 command-channel integrity obligation —
the command channel previously had NO checksum. This is the load-bearing security control of the phase.
Output: new `test_cobs_cmd_frame` Unity suite (Wave-0 scaffold) + `firestarter.cpp` surgery + `CMD_FRAME_MAX`.
</objective>
