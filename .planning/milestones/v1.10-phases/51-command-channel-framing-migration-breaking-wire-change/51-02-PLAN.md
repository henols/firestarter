framed automatically (D-04 — no plaintext escape hatch). Add the `CMD_FRAME_MAX` constant (host half

    `crc = _crc8_ccitt(json_bytes)`; `body = cobs_encode(json_bytes + bytes([crc]))`;
    `frame = body + b"\x00"`; `return self.send_bytes(frame)`.

    Encode order is LOAD-BEARING (ADR §4.3): CRC8 is computed over the RAW json_bytes FIRST, then the
    `json_bytes + crc_byte` logical stream is COBS-encoded as a unit. Never COBS-encode first then CRC the
    body — every frame would fail the firmware's CRC8 verify (RESEARCH Pitfall 2).

    `frame` MUST be a single `bytes` object passed to `send_bytes()` in ONE call (SAFE-01 sub-claim B).
    Do NOT do `send_bytes(body); send_bytes(b"\x00")` — the split-write window is forbidden and would
    break the SAFE-01 proof (RESEARCH anti-pattern).

    Do NOT add any `if cmd == CMD_FW_VERSION: send_string(...)` plaintext bypass (D-04 / RESEARCH Pitfall 4):
    there is no old peer to be compatible with (D-01), so the probe is framed like every other command and

    (`expect_ack` / `get_response` / `_read_and_parse_lines`) is UNCHANGED — out of scope (ADR §4.2).
