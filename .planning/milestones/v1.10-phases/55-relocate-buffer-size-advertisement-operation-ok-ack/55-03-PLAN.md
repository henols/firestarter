<objective>
Make the host read the relocated buffer-size advertisement from the operation-setup
`MSG_OK_READY` ack and default safely to 512 when it is absent, and remove the Phase 54
identity-string parse mechanism it replaces.

This is the host half of the dual-repo change (SC1 host side + SC3). It depends on Plan 01
(the regenerated `messages.py` with MSG_OK_READY `param_bytes=-1`) and turns the RED tests
from Plan 01 Task 2 GREEN. It runs in Wave 2 in parallel with the firmware plan (02) — disjoint
repos, zero file overlap.

The capacity is intercepted in a `_decode_id_frame` override on `SerialCommunicator` (the
designated extension seam already used by `FaultInjectingSerialCommunicator`), NOT by touching
the GATE-1.8d ring-fenced `_read_and_parse_lines` body. `_calculate_buffer_size()` returns
`firmware_max_chunk` if set, else `512` (the universally safe Uno floor) — NO
`FirmwareOutdatedError`, reversing Phase 54 D-05.

Purpose: Host degrades gracefully against un-advertising firmware while preserving EVEN-01
full-buffer chunking.
Output: Decode override + safe-default chunk sizing + identity-parse removal + updated tests.
</objective>
