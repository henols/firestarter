<objective>
Implement the Phase 53 software harness (autonomous, fully unit-tested) that the operator-witnessed
bench plans (53-03/04/05) drive. Turn the Wave 0 RED tests from 53-01 GREEN.

This phase adds NO transport behavior. It reuses the FROZEN COBS codec, CRC8, and the existing
state-machine machinery. Three deliverables:

1. `write_cycle_eprom()` in eprom_operations.py — erase -> write source image -> read-back N times ->
   independent host-side SHA-256 compare of each read-back against the source image (D-06). Reuses the
   `consistency_check_eprom()` read loop verbatim (reuse-not-duplicate). 3-way verdict (0/1/2).
2. Outgoing fault-inject hook in `send_json_command()` via a `getattr(self, "_fault_inject_outgoing",
   None)` guard placed immediately before `self.send_bytes(frame)` (D-01/D-02). Production path stays
   byte-identical; the attribute defaults to None.
3. `FaultInjectingSerialCommunicator` subclass overriding ONLY `_decode_id_frame` for the fw->host
   receive-path mutation (D-01). The GATE-1.8d ring-fenced `_read_and_parse_lines` body MUST stay
   byte-identical. Plus a `fault_inject_cycle()` operator-method and the `dev write-cycle` /
   `dev fault-inject` subcommands following the existing `dev consistency-check` Click stack and the
   `sys.exit(verdict_int)` contract (uno328pb timeouts map to 2, never collapsed to 1).

Purpose: deliver the bench-driving harness without touching the proven-green transport contract.
Output: three production files modified; 53-01 RED tests pass; full host suite green at >=70% coverage.
</objective>
