READING 4 -- the recovery, for a clone that already hit the trap
---------------------------------------------------------------------
  $ git submodule deinit -f firestarter
      Cleared directory 'firestarter'
      Submodule 'firestarter' ... unregistered for path 'firestarter'
  $ rm -rf .git/modules/firestarter
  $ git config submodule.firestarter.url git@github.com:henols/firestarter_fw.git
  $ git submodule update --init --depth 1 firestarter
  rc: 0
  firestarter_origin: git@github.com:henols/firestarter_fw.git
  head(firestarter): 4f73c80
  has_src: yes

  Order is load-bearing: `deinit` UNREGISTERS the submodule and discards the
  override, so the override must be re-set AFTER deinit, not before. Removing
  `.git/modules/firestarter` is required -- deinit alone leaves the cached module
  and the next update reuses its wrong origin.
