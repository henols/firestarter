**`grep` on PATH in this devcontainer is `ugrep`.** It honours `.gitignore` and silently under-scans.
Every command in this plan calls `/usr/bin/grep` by absolute path. There is no exception to this.

**`/usr/bin/grep -c` is not a pass signal.** It prints `0` and exits 1 on a non-matching file, so a
leg that legitimately expects zero matches captures the output into a variable and tests it with
`[ -z ... ]`, then echoes a positive token. Absence of output is never the success signal — a
command that scanned nothing produces the same silence as a command that found nothing.

**Always pass the pattern with `-e`.** A future pattern that begins with `-` exits 2 as a usage
error, which a `||` guard reads as "not found" and the gate fails open.

files are dirty (`.devcontainer/devcontainer.json`, `.gitignore`, both `.planning/graphs/` outputs,
