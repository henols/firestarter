**`/workspaces/CLAUDE.md` §"Source code comments — hard rule" is the requirement this plan
implements, and it binds the implementation too.** It forbids *writing* a comment and permits
*deleting* one. Rewriting an existing comment to drop its identifier is editing an existing comment,
which is what this sweep does; adding a new one, in any file, for any reason, is not.

**Click and argparse help text is user-facing, not commentary.** `/workspaces/CLAUDE.md` names Click
docstrings explicitly as `--help` text that must not be treated as comments; argparse description
strings are the same category by the same reasoning. The three such citations here are rewritten to
keep their meaning and lose the identifier, which satisfies both readings at once.

**Commit inside the `firestarter_app` submodule**, on the `v1.37`-slug branch.

**`/usr/bin/grep` or `git grep` only.** The bare devcontainer `grep` is ugrep, honors `.gitignore`,
and under-scans silently; a sweep built on it fails OPEN. Avoid `grep -qF` with a dash-leading
pattern — it exits 2 and fails open; use the explicit pattern flag.

**The app battery is CI-faithful only under Python 3.11.** The devcontainer is 3.12 and masks CI-only
breakage; `uv` 0.12.6 is at `/usr/local/bin/uv`. Task 3 runs the battery both ways and treats the
3.11 result as the one that counts.
