<objective>
Strip the last five planning citations out of the catalog code generator — at the meta canonical
copy, where the edit survives — and prove the two generated artifacts it produces did not move.

Purpose: the catalog code generator is one of the six survivors and carries five citations, so
TOOLS-05 covers it. But it is the one survivor that cannot be edited in the host repo: the meta copy
is authoritative, the sync script copies it into both sub-repos and asserts their identity, and a
sub-repo edit is reverted by the next sync. The sync also regenerates the firmware message header and
the host message module, so the strip has to be proven output-neutral rather than assumed so — and
the sync script's own post-copy check cannot prove it, because it compares a temporary file against
the file it has just overwritten.

D-21 places this after both sub-repo waves, so the regenerated artifacts are compared against a
settled tree rather than a moving one.

Output: three byte-identical, citation-free copies of the generator and two provably unchanged
generated artifacts.
</objective>
