<objective>
Move `diff_db.py` out of the published package repo and into the skill that is its only real
consumer, and prove the moved copy actually runs there — before anything downstream deletes the
original.

Purpose: D-05 places `diff_db.py` by name (TOOLS-04) as *relocated*, not retired, because
`.claude/skills/devtest-rootcause/` invokes it by name in six places including the command line
`seed_debug_session.py` generates. D-21 makes this Wave 1, alone: nothing downstream may delete the
host-repo original before this lands, or the documented root-cause procedure is broken in the
interim. The hazard the decision does not name is that the file resolves **both** its inputs
relative to its own `__file__`; under the skill directory those paths do not exist, so a naive `cp`
produces a script that fails closed with exit 2 and a procedure that no longer works.

Output: a working, skill-owned `diff_db.py`; a skill whose procedure points at it; and a skill that
no longer names the gate D-01 retires.
</objective>
