<objective>
Prove this phase's whole deletion recipe on the two gates that carry orphaned library symbols with the
smallest blast radius — retire each end to end, delete exactly the tests that consume its symbols, and
settle both fail-closed indexes in the same commits — so that roughly fifteen thousand lines of
subtraction follow a recipe that has already been executed once and measured.

Purpose: the operator inverted the orchestrator's relocate ruling at the 188-02 gate and chose to delete
the consumers (D-25). That makes the risk different in kind from what the previous draft of this plan
guarded. It is no longer "a relocated symbol silently diverges from its original" — nothing is relocated.
It is now **over-deletion**: a trim that takes a neighbouring test, a whole-module deletion that breaks a
module D-25 keeps, or a fail-closed index left naming a file that is gone, turning a green suite red
between two commits of this phase. Every one of those is caught here by a measured collected count and a
named-symbol assertion, not by inspection.

Output: two gates retired end to end, 66 collected tests gone with zero collateral, two fail-closed
indexes settled, a suite that collects and passes at both commit boundaries, and a measured coverage
figure before and after.
</objective>
