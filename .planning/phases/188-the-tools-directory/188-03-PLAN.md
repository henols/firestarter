<objective>
Prove the whole phase's deletion-plus-repair recipe on the thinnest gate that has one, then relocate
the largest orphaned symbol and repair all eight of its consumers — with the gate file still in
place, so the suite is green at every commit boundary.

Purpose: the central risk in this phase is not the deletion, it is the incomplete repair. Ninety-three
surviving tests break on the deletion set, forty-five of them at *collection* time, where pytest
reports ERROR and the module contributes zero results — degrading the signal for everything else the
phase did. Task 1 runs one complete cycle (relocate the symbol, repair the consumer, delete the gate
and its test and its fixture, full suite green) on the one gate with no other entanglements, so the
recipe is proven before the mass follows it. Task 2 then does the expensive relocation — the dispatch
model, eight consuming modules, forty-four tests — while its source file still exists, which is what
makes the next plan's deletion free.

Output: two test-tier helper modules, nine repaired consumers, one gate retired end to end, a green
suite.
</objective>
