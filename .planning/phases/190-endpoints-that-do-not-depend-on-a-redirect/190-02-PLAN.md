Make a stale endpoint constant impossible to ship green. Derive the two duplicated test literals from
the constant that defines them, add the independently written pin that actually fails when a constant
is edited alone, prove it fails by editing one and watching it go red, and clear the last two
firmware-slug references in the host repository's working tree.

asserted, so an f-string off the constant tracks any edit and stays green. The pin is the guard;
derivation is the de-duplication. They are different tests and this plan writes both.
Output: one new test module, two derived fixtures, two slug corrections, and a falsification
transcript.
