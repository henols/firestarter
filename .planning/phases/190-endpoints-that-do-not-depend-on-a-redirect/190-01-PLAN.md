<objective>
Repoint the three firmware release endpoints at the renamed repository, and make `fw --list` tell an
operator the difference between "the endpoint answered and there is nothing for your board" and "the
endpoint did not answer at all".

This plan carries the phase's tracer. Task 1 is a single vertical slice down the `fw --list` path —
constants, the service layer's return contract, the CLI layer's guard, stream routing and exit code
— wired end to end and proved against the live renamed endpoint. It is production work, not a probe:
every line it writes is the shipped implementation.

Purpose: URL-01 removes the redirect from the code path. URL-04's list half is what makes a mistaken
retarget visible instead of silent — an instrument that exits 0 when it fails cannot serve as proof
that an endpoint resolves, and `fw --list` is the instrument Phase 190's criterion 4 leans on.
Output: three repointed constants, a two-state return contract, a guarded handler, one adapted test
and one new test module.
</objective>
