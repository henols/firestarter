substitution; the phase's leading `type="tracer"` vertical slice is Plan `197-02` Task 2.

  <context>
    The branch this threshold controls chooses `DIP32_27C020` — socket pin 31 driven as PGM — versus
    `DIP32_STD` — socket pin 31 driven as address line A18. 166 of the 439 32-pin rows sit on the three
    forked pinouts: `DIP32_27C020` on 88, `DIP32_STD` on 70, `DIP32_27C801` on 8. A derivation that is
    off by one puts a programming pulse on an address line for a real chip in a real socket, and no test
    would catch a wrong-but-plausible substitution other than the byte-identical regeneration this plan
    runs.

    Evidence already gathered: the substitution was measured to regenerate
    `firestarter/data/chip_database.json` `cmp`-identical to the shipped file; the identity was checked
    exhaustively for every integer in [0, 2100000) with zero mismatches, and algebraically
    `(s-1).bit_length() <= 18` is equivalent to `s <= 262144`; and the eleven distinct
    `electrical.size_bytes` values in the database are all powers of two, though the identity does not
    depend on that, so a future non-power-of-two size cannot break it.
  </context>
