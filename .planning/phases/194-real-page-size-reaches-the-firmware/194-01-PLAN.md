*structural* property -- that no function on the `0x05` write path derives a page size from

<assumption_delta_decision>
**Primary noun (promoted):** the **algorithm-agnostic per-chip page-write size**.

**Decision: `promote`.** `handle->page_size` has been described in prose as "the 0x0D handler's
field". This phase makes it what the code already implied -- the per-chip page-write size for any
handler that page-writes. The general representation already exists: `database.py:553` emits the
wire key algorithm-agnostically and `json_parser.c` stores it unconditionally. Only the prose
claimed singularity. The "0x0D-only" claim is demoted to a detail of one variant: `eeprom_28c`
falls back to a named floor when the field is absent, and `flash_5v_page` refuses.

**Rationale (one line):** promoting the general field and demoting the `0x0D` claim is the only move
consistent with two handlers consuming one wire field. Adding a second parallel field alongside it
would contradict a generalisation the transport had already made.

**Record of the promotion:** U1's comment-clause deletions ARE the record -- the four inherited
comments asserting "algorithm 13 / 0x0D only" and "other algorithms' handlers never consume this
key" are the singular claim, and deleting them is what retires it.

**Invariant test:** none added. D-08's 27-row host leg and the native consumption leg already encode
the generalised intent from both sides, and a third test asserting the same property would be
redundant rather than independent.
</assumption_delta_decision>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| host to firmware serial line | `page-size` crosses here as an untrusted wire integer and is stored into `handle->page_size`. The handler is the new validation site at that boundary |
| resolved page mask to the physical page boundary | An accepted mask decides where a page-write cycle commits. A wrong value destroys bytes the operator never asked to change |
| pinned upstream XML to the emitted database | The generator reads an external artefact over the network and publishes the result to every installed host |
| native recorder to the boundary assertion | A silently truncated recording makes a boundary assertion report a property it never observed |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-194-01 | Tampering | `flash_5v_page_write_execute`'s page arithmetic | critical | mitigate | D-05 and D-06 delete the derivation and refuse rather than guess.
