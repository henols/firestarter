<environment_notes>
PATH `grep` in this devcontainer is ugrep and honours `.gitignore`, so it silently under-scans. Every
evidence-bearing command in this plan uses the absolute `/usr/bin/grep`.

`/usr/bin/grep -c` exits 1 when the count is 0, so a leg that legitimately expects 0 carries a
trailing `|| true` and is judged on its printed number, not on its exit status.

`user=play` must reach ClickHouse as a **query-string** parameter. Without `curl -G` the
`--data-urlencode` pairs become a POST body, ClickHouse falls back to the `default` user and the call
returns `Code: 194 … Authentication failed`. This was hit and reproduced during research; `-G` is not
cosmetic.

`.planning/config.json` and `tools/catalog/messages.toml` are dirty in the working tree before this
plan starts. That is pre-existing and must not be staged or committed by any task here.
</environment_notes>

    `sumIf(count, arrayMap(x -> toUInt32OrZero(x), splitByChar('.', version)) >= [2, 0, 9]) AS fixed`

    `(fixed + at_risk) > 0 AND fixed * 10 >= 9 * (fixed + at_risk) AND at_risk <= 10 AS trigger_met`.

    a float, so rounding cannot flip the verdict, and the leading `(fixed + at_risk) > 0` conjunct is
    what stops an empty window reading as MET (`0 >= 0` is true).
    The WHERE clause: `project = 'firestarter'`; `date >= today() - 90`;
    `installer IN ('pip', 'uv')` (D-04 — both legs, same filter); and
    `NOT match(version, '(a|b|rc)[0-9]|dev')` (D-05 — the PEP 440-shaped prerelease exclusion, never
    a `%b%` pattern, which would admit a future `3.0.0rc1` into the stable denominator).
