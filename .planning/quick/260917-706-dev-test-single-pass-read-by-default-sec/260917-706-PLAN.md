<objective>
Make the `dev test` read step a single pass by default, put the two-pass read-divergence
comparison behind a new opt-in flag, and take `OP_READ` out of the repeat policy so
`dedup_fingerprint` keeps its historical community grouping.

Purpose: the read step is 12-48% of total `dev test` runtime (SST39SF040 173.8s of 362.8s,
w29c040 173.8s of 514.9s, w27c040 165.2s of 1345.6s) and runs twice purely to compare the two
passes. Halving it is free wall-clock on every community validation run.

Output: `run_plan` gains a `read_runs` run count independent of `runs`; `repeat_policy_tag`
keys on the write/verify/erase multi-run ops only; `dev test` gains `--compare-reads`; the
test suite proves the default run still produces an untagged fingerprint.

All work and all commits happen INSIDE the `/workspaces/firestarter_app` submodule on branch
`v1.39-protocol-0x05-write-correctness`. No meta-repo commit, no gitlink move, no push, no PR.
