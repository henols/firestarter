## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| firmware `response.id` -> `EpromOperationError.error_code` -> `resolve_error_name` | An integer that arrived over the serial wire from an untrusted or malfunctioning peer is the resolver's only input |
| `to_dict()` -> the filed GitHub issue body | Report content crosses from this host into a public issue a stranger reads and a triager acts on |
| `messages.CATALOG` -> product source | A codegen artifact owned by a different repository is consumed here; editing it locally would fork the host from the firmware |
| `_step_dict` key set -> `_STEPS_ELEMENT_0_KEYS` | A schema change silently widening a frozen shape pin is how a report shape drifts unnoticed |
